# AI Life 2D

人間の言語や行動例を与えず、独立した個体の自己経験と系統継承から、変化する2D世界への適応と情報交換が成立するかを調べる研究。更新日：2026年10月12日。

**このプロジェクトは完成品ではありません。** 研究途中の試作実装・実験計画・記録を公開するもので、安定した採食・生存や、言語の獲得を達成したAIではありません。実装と仕様は研究の進展に応じて変更します。

PR・Issueの受付方針は次のとおりです。

- **研究内容に関連するPR・Issueは受け付けます。** 学習方法、モデル、環境設計、評価、再現性、実験結果の議論や、関連する実装の修正を対象とします。
- **ハードウェアサポートの拡大を目的とするPR・Issueは受け付けません。** 新しいGPU・機器への対応や、対応ハードウェアを増やすための移植・サポート依頼は対象外です。

現在は、採食による安定した存続を確認する段階。予測誤差の低下は観測したが、モデル幅や学習セッション数の増加による明確な存続改善は確認できていない。

次の実験は計画段階。1世界1体の小さい環境で採食を切り分け、現在のL3と、行動学習を再帰コアまで届かせる構成を比較する。複数の独立系列を使い、その後に系統間の選抜・継承を検証する。環境の追加機能や新しい学習方式はまだ実装・実行していない。

ソースは `src/ailife/`、テストは `tests/`、設定は [configs/](configs/README.md)、実行・解析の入口は [scripts/](scripts/README.md)。大容量の生データ、checkpoint、保存済みコードは `runs/` に保管する。既存の試行IDと観察URLを維持するため、過去の実行データは移動していない。

GitHubにはコード、文書、設定、集計結果と図を含め、`runs/`、仮想環境、ビルド成果物は含めない。文書内の `runs/` へのリンクやローカルの観察URLは、実験を保存した環境で参照するためのもの。

過去の長期構想は[改訂前の構想](docs/archive/concept-before-curriculum-2026-10-12.md)に保存した。現在の優先順位は研究目標と段階計画を参照する。
