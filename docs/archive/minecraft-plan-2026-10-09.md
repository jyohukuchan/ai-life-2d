# Minecraftで生涯学習する人工生命の構想

更新日：2026年10月9日

Minecraftの共有世界で、多数のAIが独立して経験から学ぶ。人間のプレイや攻略知識を事前に教えず、生存者の複製によってセッションを重ねる。その中で、個体の状況理解、内的な動機、競争、協調などがどう形成されるかを観察する。

中心となる方針は、外から生存時間やアイテム獲得に対する報酬を与えず、何を良いと評価するかも個体と世代間の選抜にできるだけ任せることである。記憶、学習、内的評価の構造は未決定であり、以下では確定している方針と検討候補を分ける。

## 実験の目的

まず、操作と感覚の関係や周囲の状況を理解できるようになることを目指す。その先で、生存に役立つ行動、個体間の競争、協調、役割の違いなどが生まれるかを観察したい。

競争や協調は期待する観察結果であり、それらを直接教えたり、報酬で誘導したりすることは現時点の方針に含めない。複雑な行動が生まれることは保証せず、その成立条件も実験の対象とする。

## 決まっている基本方針

| 項目 | 方針 |
| --- | --- |
| 環境 | Minecraftを使う。バニラに限定しない |
| 環境調整 | ワールドボーダー、難易度、死亡やセッションのルールなどを調節する |
| 個体数 | 初期実験は同じ世界で8個体を活動させることを目安にする |
| モデル規模 | 各個体で約10Mパラメータ（約1,000万）を目安にする |
| 感覚 | 通常のプレイヤー相当の視覚と聴覚のみ |
| 操作 | キーボードとマウスに相当する操作のみ |
| 事前学習 | 最初はなし。進展がない状態が続いた場合に再検討する |
| 学習の独立性 | 各個体は独立して学ぶ。個体間で学習結果を共有しない |
| 継続学習 | 世界が進行している間も学習する |
| 睡眠 | 睡眠に該当する概念を導入する。具体的な役割は未定 |
| 外的な課題報酬 | 生存時間やアイテム獲得に対する報酬は与えない |
| 内的な動機 | 内容をできるだけ事前に固定せず、その形成を観察したい |
| 死亡 | セッション内ではリスポーンしない |
| 世代交代 | 生存者をクローンし、次のセッションの初期個体にする方向 |

8個体と各個体約10Mパラメータは、初期実験の暫定的な規模である。具体的なアーキテクチャやパラメータの配分は未決定で、動作速度やメモリ使用量を測定して必要に応じて調整する。

感覚の制約を保つには、座標、ブロックの種類、他個体の状態などをゲーム内部のAPIから直接渡さない。画面に表示される体力や空腹は視覚入力に含められる。通常の感覚にはない疲労や身体状態を直接入力する場合は、感覚の条件を拡張する設計変更として扱う。

実験管理側が持つ情報と、個体が利用できる情報は区別する。死亡や配置の管理、観察用の記録に内部情報を使うことと、その情報を個体に教えることは別である。

## 個体の学習と世代交代

個体が生きている間に経験から変化することと、どの個体を次のセッションに残すかは、別の過程として扱う。

- **生涯学習**：経験から、記憶、世界の理解、行動、内的評価などが変わる。
- **世代間の選抜**：生存者の内部状態や性質が複製され、集団に残る。

生存は個体に渡す点数ではなく、複製対象を決める条件である。外的な課題報酬を与えなくても、実験全体には生存者を残す選抜が働く。

想定する流れは、個体の配置、独立した活動と学習、死亡した個体の退出、セッション終了、生存者の保存と複製、次のセッション開始である。

終了条件は未決定。一定時間で区切る案と、全滅などの条件で区切る案がある。「最後の一体になるまで」を採用すると、複数個体が共存していても終了しないため、協調や共存を観察する目的との関係を検討する。

ゲーム内での繁殖や出産はまだ定義しない。セッション間の複製によって集団を更新することで、連続世界の中で繁殖を実装する問題をひとまず切り離せる。

次の点は未決定である。

- 生存者をそれぞれ何体複製するか、次回の総個体数をどう保つか。
- 全滅した場合、どの初期状態や保存状態から再開するか。
- 生涯で得た記憶や学習済みの重みを、どこまで継承するか。
- 内的評価の仕組みや学習の更新則を継承するか。
- 複製時に変異を加えるか、経験の違いだけで個体差を作るか。
- 次のセッションでワールドや持ち物をリセットするか。

完全なクローンでも、複製後の経験が異なれば、独立した学習から違いが生じ得る。ただし、世代を重ねる仕組みとして、何が違いを生み、何が継承されるのかを明示する必要がある。

学習状態を丸ごと継ぐ場合は、経験の蓄積も選抜対象になる。記憶をリセットして学び方や内的評価の初期設定だけを継ぐ場合は、学習能力や動機の性質を選ぶ実験になる。どちらも検討対象だが、同じものとして扱わない。

## 固定構造と模倣の境界

人間のような高度に進化した仕組みを最初から用意する範囲と、生物の原型に近い単純な仕組みから成立を観察する範囲を決める必要がある。

境界は、見かけの複雑さだけでなく、何を固定し、何を個体の経験や世代交代に任せるかで考える。例えば、長期記憶を作れる構造を用意することと、食欲、好奇心、協力への好みを用意することは別である。

物理ハードウェアや固定アーキテクチャは事前に吟味する。少なくとも、以下の設計範囲を区別する。

| 部分 | 検討内容 |
| --- | --- |
| 感覚と操作 | 映像、音、操作の関係をどう表現し、学ぶか |
| 記憶 | 直前の状況と長く保持する知識をどう扱うか |
| 可塑性 | 経験で変化できる箇所と、固定する箇所はどこか |
| 内的評価 | 評価信号を持つか、その生成や変化をどう実現するか |
| 行動選択 | 評価、記憶、探索が操作にどう作用するか |
| 睡眠 | 記憶整理や内部の更新をどう行うか |
| 継承 | どの状態や仕組みを次の個体に複製するか |

外的な課題報酬を与えないことと、学習目的や更新則も固定しないことは異なる。例えば、次の映像や音の予測誤差で世界の理解を学習させる案は、生存や採集の報酬を与えない条件を保てるが、「予測を学ぶ」という目的は人間が設定する。この範囲を許容するかは未決定である。

## 内的評価と報酬の検討候補

以下は比較用の候補であり、いずれも採用は決まっていない。Minecraftでの効果や創発は検証事項である。

| 候補 | 仕組み | 最初から与える前提や主な論点 |
| --- | --- | --- |
| 報酬なし | 経験で記憶や接続を変え、生存者だけを複製する | 更新則と探索の仕組みは必要。単なる変化から有用な学習が成立するかを見る |
| 恒常性 | 身体の不足や損傷が改善することを良いとする | 望ましい身体状態と、それへ戻ることを好む性質を固定する |
| 新しさや予測誤差 | 未知の状態や予測と異なる結果を好む | 探索への好みを固定する。学べないランダムな現象への偏りが論点 |
| 学習進捗 | 以前より予測や理解が改善した経験を好む | 理解の改善を好む性質を固定する。生存に役立つとは限らない |
| Empowerment | 自分の操作で将来の状態に作用できることを評価する | 制御可能性を好む原理を固定する。単なる画面変化量とは異なる |
| 行動の多様性 | 異なる行動から区別できる結果を生む技能を学ぶ | 多様性を良いとする基準と、技能の区別を用意する |
| 報酬生成部の継承と変化 | 各個体に内的報酬を生成する部分を持たせ、生存者から複製する | 報酬生成部の初期差、継承範囲、変化の仕組みを決める |
| 報酬生成のメタ学習 | 行動学習の結果を使って、報酬の作り方を学ぶ | 外側に何らかの評価基準が必要。生存者選抜だけでどう更新するかが課題 |

報酬生成部を持たせる案は、現在の構想に直接近い候補である。感覚と記憶から評価を生成する方式と、恒常性や新しさなどの候補信号を組み合わせ、その重みを変える方式が考えられる。後者は探索する範囲を絞れる一方、動機の材料を人間が先に決める。

個体の生涯の中で報酬生成部を学習させることと、世代間の選抜で報酬生成部の性質を残すことも区別する。自分の報酬を高くするだけでは、世界への適応を学ぶことにならないため、報酬生成部の更新を行動学習と同じ基準にするかどうかは慎重に設計する。

比較条件として、報酬なし、個体ごとに異なる報酬生成部、身体の不足改善を評価する固定報酬の三案が挙がっている。好奇心や学習進捗を追加する案もあるが、比較条件は未確定である。

## 睡眠と継続学習

睡眠に該当する概念を導入することは決まっているが、その機能、開始条件、長さ、個体にとっての動機は未定である。

睡眠の候補機能は、実体験の再処理、短期記憶から安定した知識への移行、不要な記憶の整理、内部で生成した経験による再学習である。活動中にも学習し、睡眠中は内部の処理を重点的に行う構成を検討する。

世界を進行させたまま個体が眠る場合、睡眠はその個体の生活上の状態と、学習処理の両方に関係する。次の二案では、最初に与える動機が異なる。

- 疲労とその解消を用意し、休息を好む性質を与える。
- 記憶整理などの機能だけを用意し、睡眠を利用する個体が選抜で残るか観察する。

## アーキテクチャの参考論文

### Nested Learning

[Nested Learning: The Illusion of Deep Learning Architectures](https://arxiv.org/abs/2512.24695) は、学習を複数の更新速度を持つ最適化過程として捉え、更新を調整する自己修正機構と、異なる時間尺度の記憶を組み合わせたHopeを提示している。

今回の構想では、活動中の素早い適応と、長く保持する知識を両立する記憶設計が参考になる。動機や報酬そのものの自然発生を実証した研究ではなく、未学習の個体が感覚と操作から自律的に育つことも、この論文だけで保証されない。

### Language Models Need Sleep

[Language Models Need Sleep: Learning to Self-Modify and Consolidate Memories](https://arxiv.org/abs/2606.03979) は、Nested Learningの記憶構造を土台に、睡眠中の記憶固定と生成データによる自己改善を扱う。

睡眠に学習上の役割を与える設計が参考になる。ただし、実装では教師との一致度や課題成績の改善を報酬に使っており、既存の言語モデルを使った実験も含まれる。報酬を自律的に形成する仕組みとして、そのまま採用するものではない。

これらの記憶と睡眠の発想を取り入れる範囲は未決定。生成した経験だけで自己改善する段階より先に、実体験の保持や、操作と感覚の関係が学べるかを確認する案がある。

## 次に決める設計事項

1. どの構造を固定し、何の成立を学習や選抜に任せるか。
2. 予測誤差など、人間が定める学習目的をどこまで許容するか。
3. 内的評価を持つか、持つ場合に生成と変化をどう実現するか。
4. セッションの終了条件、複製数、全滅時の扱い。
5. 記憶、重み、報酬生成部、学習の更新則の継承範囲と変異の有無。
6. 睡眠の機能と、睡眠を利用する動機を固定する範囲。
7. ワールド、資源、難易度、初期配置などの条件。
8. 進展の指標と、事前学習なしの方針を再検討する条件。

進展の候補指標には、操作結果の理解、行動の変化、経験の保持、新しい世界への適応、内的評価の変化、競争や協調などがある。生存率や生存時間も観察用に記録できるが、個体に学習報酬として与えることとは区別する。
