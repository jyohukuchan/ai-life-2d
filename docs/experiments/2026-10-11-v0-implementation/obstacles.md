# 疎な固定障害物の追加

2026年10月11日。新規世界の内部タイルの約4%に、一辺1〜4タイルの小さな塊や短い壁を配置した。自由な外周通路と塊の間の通路を残し、全ての通行可能タイルがつながる生成方式を使う。世界ごとの専用乱数で実行前に生成する。

移動、初期個体の配置、出生、食料の初期配置・再生に同じ通行判定を使う。個体の局所RGB視覚、ライブ、世界一覧、個体追跡の視覚、リプレイにも障害物を反映する。静的な地形はリプレイごとに一度保存する。設定は `obstacle_density`、CLIは `--obstacle-density`。範囲0〜0.2、0は障害物なしの比較条件。

検証結果：

- pytest **31件成功**。通行可能タイルの連結、配置の再現性、移動・出生の阻止、食料・個体の配置、回転した局所視覚、保存再開、リプレイの新旧形式を検査した。
- サイズ7〜149、密度0・0.01・0.04・0.1・0.2、各5シードで生成数を確認した。
- R9700でL3・3世界・各1,800tickを完走。約45.5秒、合計118.8世界tick/秒。各57×57世界の内部障害物は121タイル。最終生存数36・32・28。複製出生151、二親出生41を記録した。短い機能確認であり、以前の障害物なし条件との効果・性能の比較実験ではない。
- Chromiumでライブとリプレイの障害物表示、本人の回転した局所視覚の画素、旧リプレイの表示を確認。JavaScriptエラーなし。リプレイ停止中もtick 762から826へ進んだ。
- 以前に保存した実際のcheckpointを再開し、障害物を追加せず、旧コードで継続した世界・ネットワーク重みと一致することを確認した。
