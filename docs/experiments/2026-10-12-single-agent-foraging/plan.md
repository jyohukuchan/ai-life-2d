# 1世界1体の反復採食と、学習経路の比較

実験ID：`2026-10-12-single-agent-foraging`。作成日：2026年10月12日。

状態：研究計画に採用。環境較正、新機能の実装、学習実験は未実施。以下の数値候補は本比較の開始前に較正・固定する。[研究目標](../../overview/research-goals.md)と[段階計画](../../overview/roadmap.md)に従う。

## 1. 背景と問い

[各条件20系列の比較](../2026-10-12-width-session-replication/results.md)では、hiddenや入力幅、セッション数を増やしても明確な存続改善を確認できなかった。共通マップ評価120件は全て6,590tick以内に全滅し、終盤の採食もなかった。5→20セッションで予測誤差は約16%下がったが、各モデルが自ら得た観測上の値で、同じ入力列での比較ではない。

次の問いを切り分ける。

1. 世界の要素と必要な操作列を減らせば、現在の学習で継続した補給を獲得できるか。
2. 行動・価値の学習を再帰コアへ届かせ、時間方向にも学習すれば改善するか。
3. 行動学習が成立した後、内的評価と獲得重みの系統選抜・継承に効果があるか。

反復採食、存続、条件変更後の回復を測る。予測誤差の低下だけで適応成功としない。

## 2. 維持する条件

人間の言語・プレイ・攻略例による事前学習を行わない。個体の重み、記憶、勾配、経験、optimizer、正規化統計は独立。採食・生存・通信等への固定の外的課題報酬を追加しない。診断用方策や他個体の経験を学習データとして渡さない。

局所RGB、許可した体内エネルギー感覚、絶対方位を基準にする。旋回と前進は相対操作を維持し、全体地図、真の座標、食料ラベルを入力しない。視野半径5は最初の比較では固定する。

モデルはhidden 64・入力エンコーダ32を軽い基準にする。研究全体の固定規模ではない。まずFP32・compiledを基準にし、TF32の扱いを記録する。新backendが未対応なら方式間で共通に動く実行方式にそろえ、速度の比較と能力の比較を分ける。

## 3. 簡略世界

| 項目 | 計画 |
| --- | --- |
| 個体数 | 1世界1体、初期数・容量とも1。独立した複数世界を使う |
| 地形 | 小さい長方形、外壁あり、内部障害物なし。1:4の比率には固定しない |
| 寸法 | 短辺7以上という現実装の制約内で較正する。候補例は8×12、10×16で、採用値ではない |
| 食料 | 一種類、有限のエネルギーを補給。再供給があり、最初の成功を経験しやすい距離に置く |
| 配置 | 左出生・右食料の長距離移動条件を外す。食料位置と初期の向きを変え、方向の丸暗記を防ぐ |
| 再供給 | 同じ場所の連続採食だけで維持できない条件を検討する。位置変更・再生待ち等の方式と供給予算を固定する |
| 行動 | 静止、前進、左右旋回、正面の採食。通信・繁殖を無効化し、不要な行動成分を内的評価からも除く |
| 死亡 | エネルギー不足を残す。寿命死は無効化。終了上限への到達は死亡と扱わない |
| 世界内の出生 | なし。死亡後に同一個体を自動補充しない |
| 観察 | 実時間非同期の画面と、試行前に無作為選定した連続区間のリプレイを保存 |

視野内に世界の大部分が入っても、最初は反復採食の診断として許容する。記憶や長距離探索の成立は別段階で確認する。地図縮小に伴う総供給量、食料密度、移動費の変化を明記し、元の較正値をそのまま移さない。

ランダムが永続できるほど食料を増やすことは避ける。一方、一度も採食しないまま死ぬ設定も採用しない。「偶然に複数回成功する機会」と「意図した反復補給が必要な長期」を両立する範囲を探す。

## 4. 段階0：世界の成立性を先に確認

学習なしの完全ランダムと、同じ局所観測・操作しか使わない単純な診断用方策を走らせる。診断用方策は環境が成立するかの確認専用で、学習個体に行動例や正解として渡さない。

診断用方策が繰り返し採食して維持でき、ランダムが複数回の経験機会を得つつ長期維持できない設定を候補とする。採食回数だけでなく、実際に体内へ入ったエネルギー、代謝・移動費、食料の再供給、体力上限で失った分を確認する。どの方策でも維持できなければ、学習方法を評価する前に世界を修正する。

調整用seedと未使用の確認用seedを分ける。食料の数、再生率、代謝、移動費を同時に大量掃引せず、資源収支を確認しながら少数候補を試す。予備較正のデータを、本比較の独立確認として数えない。

## 5. 段階A：生涯中の行動学習

まずセッション間の選抜・継承を入れず、新しいランダム初期個体から始める。環境と学習方式を次の2×2で比較する。

| 環境 | 現在のL3の更新経路 | 改善候補の更新経路 |
| --- | --- | --- |
| 簡略世界・1体 | 要素を減らすだけで改善するか | 最小課題での適応を確認 |
| 現在の96×32世界・初期32体 | 従来の基準 | 元の課題にも改善が及ぶか |

環境要因には、個体数、地図、出生、寿命等の複数変更が含まれる。差を地図サイズだけの因果効果とは解釈しない。また、異なる環境の存続tickを直接能力の順位にしない。それぞれの環境内で、対照に対する改善を評価する。

各環境に完全ランダムと、同じ初期重みから重み更新を止めた対照を置く。更新停止でも再帰状態と観測統計は変わる現行L0の意味を明記する。条件間で可能な範囲の物理初期状態とseedを対応づけ、学習用の重み・経験は共有しない。行動空間の違いにより完全一致できない乱数は別に記録する。

### 学習方式の改善候補

現在のL3は、行動・価値ヘッドを更新する一方、GRUには予測学習だけが届く。予測BPTT長は1で、内的評価係数とGRU後の特徴Linearは生涯中に固定される。

改善候補では、行動・価値の損失が特徴層、再帰コア、入力エンコーダまで届くようにする。GRUの数値状態の保持だけでなく、短い経験列を通じて記憶の作り方を学べる更新にする。初期候補は列長16、32は追加比較候補。列の境界、勾配の切断、死亡時の処理を仕様化する。

最初は各実遷移を一度使う短い列の学習を優先し、経験の再利用回数まで同時に増やさない。個体専用replayは追加条件として扱う。新方式ではoptimizerや更新頻度の変更もあり得るため、差をBPTT長だけの効果とは呼ばない。有望なら、コアへの行動勾配、列長、経験再利用を個別に切り分ける。

内的評価の基底と係数は、同じ簡略環境の新旧方式間でそろえる。改善候補だけに採食を好む係数を与えない。不要な通信・繁殖の成分を落とす変更は両方式へ共通に適用する。

予測と行動の勾配が競合する可能性を記録する。予測損失の寄与、各部分の更新量、勾配ノルム、実遷移数と学習更新回数、計算時間を保存する。全生涯の計算グラフは保持しない。

現行の `learn()` を繰り返し呼ぶだけで再学習を実装しない。観測統計、hidden、行動履歴、報酬統計、トレースは実際の時間に一度だけ進め、保存経験を使う最適化と分離する。

[RTU-RTRL](https://arxiv.org/abs/2605.24709)は、部分観測・逐次更新を保つ別候補として残す。対角再帰構造による計算量の性質を一般のGRUへそのまま当てはめない。今回は列学習と同時に導入しない。

### 判定と分岐

- 診断用方策だけが成功する：物理的には成立する。内的評価と行動更新の関係を調べる。
- 現行L3も簡略世界で成功する：環境側の要求を段階的に戻し、どこで失敗するか調べる。
- 改善候補のみ成功する：学習経路の変更が有望。変更内の機構を追加比較する。
- 内的報酬は上がるが補給が成立しない：動機と生存の不一致を調べる。予測能力やモデル規模だけの問題としない。
- 両方式とも補給に失敗する：難化・通信追加へ進まず、内的評価、更新則、探索を小さい課題で切り分ける。

簡略世界で現行L3が失敗しても、直ちに実装バグや能力不足と断定しない。現在の遺伝評価器が生存に役立つ動機を持つとは限らず、その評価器は段階Aでは進化しない。

## 6. 段階B：複数系統の選抜・継承

1世界1体を維持しながら、複数の候補系統を一つの選抜集団として扱う。集団自体を独立に初期化した反復を複数用意する。一体を毎回継ぐだけの条件と、系統間の選抜がある条件を区別する。

候補系統は同じ環境条件・同じ時間上限で比較し、地図の偶然だけで選抜が決まらない評価設計を固定する。生存者からの無作為選抜、全滅時の存続時間による選抜を候補とし、採食回数や予測誤差を暗黙に適応度へ加えない。全員が存続した場合は順位を捏造せず同順位とする。選抜用に分岐した評価の学習状態は、本系列へ戻さない。

継承する獲得重み、内的評価係数、学習率、入力校正を明記し、新しい身体・再帰状態・optimizer・トレース・報酬統計・経験バッファの初期化規則を固定する。別個体の重みの平均や、経験バッファの共有は行わない。

世界内の出生を止めると、従来の出生時変異もなくなる。選抜・複製だけでは新しい内的評価係数は生じない。動機の進化を調べる段階Bでは、セッション境界の変異の適用範囲・強度を別に定め、変異なしの継承と区別する。変異を本人の生涯学習と混同しない。

選抜集団内の世界は共通祖先と選抜履歴を持つため、世代を重ねた後も独立な標本とは数えない。統計的な反復単位は独立した選抜集団。複製後の学習状態が独立であることと、結果が統計的に独立であることを区別する。

段階Bの集団数、候補数、セッション数、変異強度、選抜規則は未決定。段階Aの結果と計算費を踏まえ、開始前に固定する。

## 7. 指標と評価

| 対象 | 観察指標 |
| --- | --- |
| 反復採食 | 総採食と終盤の採食、採食間隔、実際の補給量、別位置での補給 |
| 資源収支 | 代謝、移動費、補給、上限で失った分、エネルギー推移。繁殖を戻した条件は移転と散逸費も分離 |
| 存続 | 固定上限までの生存と、上限までの制限平均生存時間。上限到達を死亡扱いしない |
| 学習 | 更新停止との対応差、内的報酬の成分、行動分布、予測・行動の更新量 |
| 元の集団環境 | 最後の死亡tickに加え、全個体の総生存tick、年齢、出生時期、終盤補給 |
| 変化への適応 | 配置変更直後の低下、補給再開までの時間、未使用地図での維持 |
| 計算費 | 実遷移、更新回数、世界tick、個体判断数、実時間、RAM・VRAM、保存量 |

予測誤差は自分の軌跡上の値と、比較用に固定した観測・操作列上の診断値を分ける。固定列は評価専用で、事前学習や個体間の経験共有に使わない。

成功基準は、ランダム・更新停止を上回る反復補給、終盤の有効な採食、エネルギー収支、複数の未使用seedでの再現を組み合わせる。単に初期の食料を早く食べ尽くしたこと、静止による節約、一回の長寿命を成功としない。

予備測定後、本比較前に評価上限、終盤区間、必要な差、独立反復数、打ち切り処理を固定する。対応のある比較は対応差と不確実性を報告し、多数の比較と探索的解析を明記する。系列の途中保存点や同祖先のコピーを標本数へ加算しない。

## 8. 実装前の確認と記録

| 項目 | 現在の対応と必要な作業 |
| --- | --- |
| 1体・小マップ | 設定可能。最小寸法と容量の検査を維持する |
| 寿命死の無効化 | 明示的な無効化設定は未実装。無効化時の死亡判定・不変条件・保存再開を定義する |
| 繁殖無効 | 現在はboth/clone/sexualのみ。容量1で出生を妨げる方法を、繁殖無効と読み替えない |
| 通信と不要行動 | symbols=0は設定可能。不要ヘッド・評価基底の整理は別途必要 |
| 食料の再配置・供給 | 既存の確率再生と、今回の再配置規則を区別して実装・記録する |
| 時系列学習 | 新しい比較backend、死亡をまたがない列、個体別状態、保存再開が必要 |
| セッション間選抜 | 現行は世界内の個体から選抜する。世界をまたぐ系統プールは新規仕様 |

最初に旧backendの互換性と、新機能の有効・無効時の世界更新を検証する。出生を外した条件では余分な出生コストや評価寄与が残らないこと、寿命無効でも空腹死が働くことを確認する。検証で更新した重みは本比較に使わない。

計画版、完全設定、seed一覧、source hashと保存コード、初期・終了状態、内的評価、継承・変異の履歴、指標、リプレイ選定を残す。既存の `runs/` 直下の試行ID方式を使い、観察サーバーが読めない階層へ移さない。

この文書を反映した時点では実行用YAMLを作らない。未対応の機能を既存設定だけで実現したように見せず、数値較正と実装の完了後に `configs/experiments/2026-10-12-single-agent-foraging/` へ確定設定を追加する。
