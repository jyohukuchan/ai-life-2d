# 研究目標と条件

更新日：2026年10月12日。現在の方針の基準文書。実装済みの仕様は[学習v0](../protocols/learning-protocol-v0.md)、具体的な次の比較は[単独採食実験](../experiments/2026-10-12-single-agent-foraging/plan.md)に分ける。

## 最終目標

十分な知能と適応能力を獲得したAIなら、人間の世界について教えるのを最後にしても適応できるのではないか、という仮説を検証したい。

人間世界への適応は長期的な検証対象。2D世界の生存や独自の通信が成立しても、この仮説の実証とはしない。どんな能力が別環境へ移るか、どれだけの追加経験で学べるかを段階ごとに測る。

## 現時点の目標

人間の言語や行動例を与えず、自己経験と系統継承から、未経験の2D環境で生存に必要な行動を獲得し、他個体との情報交換を新しい状況にも利用できるようになるかを調べる。

- 様々な2D世界に適応できる個体を育てる。既知の地図の攻略と、条件変更後の学習能力を区別する。
- 人間の言語を教えずに、意味を持つ情報交換と、状況を越えて使える表現が形成されるかを調べる。
- 生涯学習、獲得した性質の継承、選抜・変異による系統の変化を区別して測る。
- 生物の進化を参考にするが、計算資源の制約に応じて簡略化する。身体、感覚、学習則、出生条件に人間が入れた前提を記録する。

直近の目標は、1世界1体の小さい環境で、偶然の採食から継続したエネルギー補給へ移れること。ランダムと重み更新停止の対照に比べた改善、および食料配置変更後の回復を確認する。

## 守る条件

| 項目 | 方針 |
| --- | --- |
| 事前学習 | 最初は使わない。人間のプレイ、言語、攻略例、他個体の経験を学習データとして渡さない。停滞時の再検討は別の判断として記録する |
| 学習の独立性 | 個体ごとに重み、経験、記憶、勾配、optimizer、統計を独立に持つ。GPUでまとめて計算しても共有しない |
| 外的な課題報酬 | 生存時間、採食、通信、協調、繁殖等への固定加点を主実験に導入しない |
| 内的評価 | 内的評価の形成・継承・変化を観察する。どの部分が生涯内に変わり、どの部分が選抜で変わるか明記する |
| 選抜 | 生存による管理側の選抜と、個体に入力する内的報酬を分ける。観察指標を暗黙に適応度へ加えない |
| 感覚と操作 | 局所的な感覚と身体操作を使う。基準は局所RGB、許可した体内感覚、絶対方位と相対的な旋回・前進。全体地図、真の座標、物体の意味ラベルは渡さない |
| 言語 | 通信路・帯域・送受信方法を用意する。信号の意味、正解文、文法は用意しない |
| 死亡と出生 | 同一個体の自動リスポーンを行わない。管理側の新セッション、複製、世界内での出生を別イベントとして記録する |
| 規模 | 個体数・モデルのパラメータ数を研究全体の固定条件にしない。次の実験の軽い基準はhidden 64・入力幅32 |
| 時間と観察 | 実時間に同期させず進める。観察は別処理でゲーム画面・リプレイを提供する |

固定の課題報酬を与えなくても、予測損失、身体ルール、選抜、変異、カリキュラムには設計者の前提が入る。「何も教えていない」という表現だけで済ませず、与えた構造を比較できる形で記録する。

## 研究の進め方

一瞬で全滅する環境では、繰り返して経験する機会が少ないと予想する。一方、ランダムでも維持できる環境だけでは、生存能力の差を測りにくい。偶然の成功を複数回経験でき、習得可能な行動で長期維持できる環境を較正する。

環境と学習機構を小さく比較し、重みを継承しながら、難易度・要素数・条件の多様性を段階的に増やす。反転、回転、食料位置や供給周期の変更は、難化と分けて扱う。以前の環境も残し、忘却を測る。

事前準備を作り込んで一回の学習から高度なAIが生まれることを期待する進め方は採らない。予測誤差の低下、行動の改善、個体の存続、系統の維持、未知環境への適応を、それぞれ独立した証拠として積み上げる。
