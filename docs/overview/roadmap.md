# 段階計画

更新日：2026年10月12日。各段階の開始条件と次へ進む証拠を定める。段階は一方向に固定せず、失敗した能力まで戻って原因を調べる。

| 段階 | 環境・比較 | 確認したい能力 | 次へ進む証拠 |
| --- | --- | --- | --- |
| 0：基盤と成立性 | 保存再開、観察、ランダム、同じ感覚・操作の診断用方策 | 実装が正しく、資源収支上も存続可能 | 診断用方策が反復採食で維持できる。ランダムは経験機会を得るが長期維持できない |
| 1：単独の採食 | 1世界1体、小マップ、食料一種類、繁殖・寿命死・通信・障害物を外す | 観測と操作から継続した補給を学ぶ | 学習ありで更新停止・ランダムより改善し、終盤も有効な補給を続ける |
| 2：環境変化への適応 | 配置変更、反転・回転、供給周期、障害物、記憶が必要な状況を一つずつ追加 | 固定した攻略の再現から、変化への適応へ進む | 未使用地図での成績と、変更後の回復速度が改善し、以前の課題も保持する |
| 3：系統と相互作用 | セッション間の選抜・変異・継承を切り分け、その後に世界内の繁殖・競争を戻す | 有用な動機と学習能力が系統に維持される | 複数世代の維持と、無選抜・変異なし等の対照との差を確認する |
| 4：情報交換 | 情報や操作能力が異なる個体を置き、意味を定めない通信路を用意 | 他個体の信号を判断に利用する | 受信への介入で行動・成果が変わり、未知の相手や状況でも利用できる |
| 5：環境の改変と広い転移 | 運搬、狩り、建築、複数資源、更新頻度の異なる記憶・睡眠を必要に応じ追加 | 学んだ機構を多様な世界で使う | 複数課題の保持、未知の組合せへの適応、追加計算に見合う改善を示す |

段階0の実行基盤は存在するが、次の簡略世界の成立性は未確認。段階1が現在の優先事項で、[単独採食の比較計画](../experiments/2026-10-12-single-agent-foraging/plan.md)に具体化する。段階1の生涯学習と、段階3の系統選抜は別の比較にする。通信の小さい診断課題は基本的な適応が成立した後、世界内の繁殖を全て戻す前でも検討できる。

## 環境を変える基準

ランダムが死ぬことだけで採用しない。同じ局所観測と操作制約の診断用方策で存続できること、学習個体が反復経験を得られることを確認する。全体地図を見られる方策だけが成功しても、個体の条件で学習可能だという証拠にしない。

習得を確認した課題に少数の変化を加える。以前の課題・難易度を訓練に混ぜ、未知条件は評価用に確保する。進級の数値条件、評価期間、独立系列数は予備較正の後、本比較を始める前に固定する。

能力の境界に合わせて環境を変える考え方は[ACCEL](https://proceedings.mlr.press/v162/parker-holder22a.html)を参考にする。同研究の学習目的や教師アルゴリズムを、そのまま本研究へ導入する決定ではない。

## 学習機構を変える基準

まず行動学習が再帰コアへ届く構成と、短い経験列で時間方向にも学ぶ構成を比較する。個体専用の経験再処理、RTU-RTRL、更新頻度の異なる記憶、睡眠は、その比較の後に追加効果を測る。複数機構を一度に入れた差から、一つの機構の効果を断定しない。

予測だけが改善する場合は、同じ入力列での予測評価と、内的報酬・行動・エネルギー収支を調べる。単純に幅や試行時間を増やす前に、予測、動機、行動学習、選抜のどこで改善が止まるかを確認する。

## 言語へ進む基準

情報交換の利益がある状況を設計する。例えば、一方が見た資源情報を他方の操作に利用でき、両者の存続に関係する状況を使う。記号の意味は指定しない。

発信頻度や信号と行動の相関だけで成立としない。受信の遮断・入れ替え、相手の変更、新しい状況・組合せへの評価を使う。[測定上の落とし穴](https://arxiv.org/abs/1903.05168)を踏まえ、受信が判断に作用する通信と、状況を越えて使える言語的な表現を分ける。
