# 相対操作を維持した絶対方角の入力

2026年10月11日。方角推定の負担を減らすため、常時読める方位センサーを追加する。現在の較正環境（縦96×横32、基礎代謝0.016、再生率0.00001）で、方角あり・なしのL3を比較する。

## 操作と観測

待機、現在の正面へ1タイル前進、左へ90度旋回、右へ90度旋回の4択を維持する。視野は半径5・11×11タイルで、身体の正面が画像の上。視野拡大やランドマークはこの比較では追加しない。

`compass` は次の3設定を持つ。

| 設定 | 方位入力 | 用途 |
| --- | --- | --- |
| `absolute` | 北・東・南・西の順の4次元one-hot | 方角あり |
| `masked` | 同じ4入力を常にゼロ | 同じ大きさの方角なし対照 |
| `none` | 入力枠を追加しない | 過去の試行・checkpointとの互換性。既定値 |

`absolute` の方角はワールドの4方向で、身体が右へ旋回すれば北→東→南→西→北と変わる。子は自身の身体の向きを受け取り、死亡遷移にはスロット再利用前の旧個体の最終方向を使う。

座標、食料までの方向、目的地、他個体の内部状態は与えない。観察画面では、個体を選ぶと「方位入力」に方角または「なし」を表示する。

## 学習への入れ方

基礎観測のRGB・受信音・自己エネルギーは従来どおり368入力。方角あり・なしの比較では、その後ろに4入力を付けて観測を372入力にする。エンコーダには、正規化した基礎観測、直前の自己行動14入力、正規化しない方位4入力の順で渡す。

方角はエンコーダと方策を条件付ける入力に使う。次の方角を当てる追加課題は作らず、予測対象は従来の基礎観測368入力のまま。予測損失のモダリティごとの配分も維持する。内的評価の特徴22個にも方角を追加せず、自己エネルギー変化の添字も基礎観測内に固定する。視聴覚以外の感覚として、方位センサーを明示的に導入する条件である。

追加される重みはエンコーダの4×32＝128個。方角あり・なしはともに65,625パラメータ/個体となる。過去の入力枠なしのL3は65,497であるため、今回の主対照には新たに実行する `masked` を使う。

## 比較と初期化

L3の両条件を同じ3シード（42・1051・2060）、同じ初期世界・遺伝基底・重み・状態から開始する。CPUで一度だけ未学習状態を生成し、条件ごとのtick 0 checkpointへ保存する。過去の学習結果は使わない。観測履歴、再帰状態、optimizerの更新回数はすべてゼロで、重みは遺伝基底と一致する。

同じ初期状態のコピーは実験条件間の対応付けである。各世界内の個体は異なる個体別重みと独立した学習状態を持ち、活動中に経験・重みを共有しない。両L3を同型のV620で実行し、GPUのアーキテクチャも揃える。方角を使わないRANDOMはR9700で参考試行として実行する。

方角入力が有効かどうかの比較であり、方角を使った生涯学習の寄与だけを切り分ける比較ではない。入力は初期のニューラル方策や世代間選抜にも影響し得る。L0との比較は別の検証になる。

## 検証・再実行

既存分を含む53件のテストが通った。4方向と相対操作、同一初期重み、対照のゼロ入力、方角を報酬・予測対象に入れないこと、死亡時の方向、保存再開、条件名の表示を検証した。GPU上でも両条件の学習更新・有限性と評価器の特徴数を確認した。方角設定を途中で変えるresumeは拒否する。

```bash
# 初期状態を用意する（出力先は新規ディレクトリ）
.venv/bin/python scripts/prepare_compass_experiment.py \
  --base configs/experiments/2026-10-11-feeding-calibrated-l3/feeding-calibrated-L3.yaml \
  --output runs/compass-ablation-initial --config-prefix configs/compass

# 方角あり
ROCR_VISIBLE_DEVICES=0 .venv/bin/ailife run \
  --config configs/experiments/2026-10-11-compass/compass-absolute.yaml \
  --resume runs/compass-ablation-initial/absolute.pt \
  --device cuda:0 --output runs/MY-COMPASS-L3

# 方角なし。別GPUの独立プロセスで実行できる
ROCR_VISIBLE_DEVICES=1 .venv/bin/ailife run \
  --config configs/experiments/2026-10-11-compass/compass-masked.yaml \
  --resume runs/compass-ablation-initial/masked.pt \
  --device cuda:0 --output runs/MY-MASKED-L3
```

`--compass absolute` / `--compass masked` / `--compass none` は新しい試行のCLIでも指定できる。設定変更による再開は許可しない。
