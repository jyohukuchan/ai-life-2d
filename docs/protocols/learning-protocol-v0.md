# v0の学習更新と個体状態の仕様

これは現在のv0 backendの仕様。[次の比較計画](../experiments/2026-10-12-single-agent-foraging/plan.md)にあるコアへの行動学習や時系列学習は未実装で、この仕様には適用されていない。入力エンコーダは現在 `encoder_width` で可変、下図の32は既定値。GRUの状態幅は `hidden`。

更新日：2026年10月11日

[実験計画 v0](../experiments/2026-10-11-v0-implementation/plan-v0.md)のL0〜L3を実装するための更新手順を定める。数値は初期実装の基準であり、この人工生命環境での有効性を実証した値ではない。個体数とパラメータ数の固定条件は設けない。

## 共通構造と更新対象

感覚を固定順で平坦化し、直前の自己行動のone-hotを連結する。 任意の方位センサーを使う比較では、さらに北・東・南・西の4入力をエンコーダへ連結する（[方位入力の仕様](compass-input-design.md)）。方位は条件付け専用で、基礎観測の正規化・予測対象・内的評価の特徴には追加しない。出生後の最初の行動履歴はゼロにする。v0はMLPエンコーダを使い、CNNとの比較は別設定とする。

```text
局所画像・受信音・許可した体内感覚・直前の自己行動
 → Linear(d,32) → LayerNorm → LeakyReLU(0.01)
 → GRUCell(32,h) → LayerNorm
 → Linear(h,h) → tanh → z_t
                       ├→ 成分別の線形行動ヘッドとsoftmax
                       ├→ 線形の内的価値ヘッド（L3）
                       └→ 線形の次感覚予測ヘッド（L2・L3）
```

LinearとGRUの創始重みは、各入力行列のfan-inをfとして標準偏差`1/sqrt(f)`の正規乱数、biasは0、LayerNormのscaleは1・offsetは0で初期化する。個体別の乱数を使う。行動ヘッドには特殊な攻略初期値を与えない。疎初期化はこの基準には入れず、別の比較候補とする。

| 方式 | 生涯中の重み更新 | 固定する部分 |
| --- | --- | --- |
| L0 | なし。再帰状態と共通の観測正規化統計だけ変わる | 全ネットワーク重み |
| L1 | GRU後のLinear(h,h)の重み行列Aだけを局所Oja則で更新 | エンコーダ、GRU、特徴層のbias、行動ヘッド |
| L2 | 次感覚予測でエンコーダ、GRU、予測ヘッドをAdam更新 | GRU後のLinearと行動ヘッド |
| L3 | L2と同じ感覚更新に加え、行動・価値ヘッドを下記のStream-AC由来の規則で更新 | 遺伝評価係数、GRU後のLinear。RL勾配は感覚コアへ流さない |

感覚更新のパラメータ群は、エンコーダのLinearとLayerNorm、GRU、GRU直後のLayerNorm、予測ヘッドである。GRU後の特徴Linearは含めない。行動・価値ヘッドの群はそれぞれの重みとbiasだけで、感覚群と重ならない。各方式で存在するパラメータと実際の更新対象を設定とログへ出力する。

L1のpre活動xはLayerNorm後のGRU出力、post活動yはtanh出力とする。`ΔA=(eta_plastic/h)×(y x^T - diag(y^2) A)`を遷移後に適用し、各行のL2ノルムを上限2へ射影する。これは局所則を限定した比較条件であり、適応の成立を保証しない。

LayerNormは一個体の一観測の特徴軸にだけ適用する。個体や世界をまたぐBatchNorm、勾配ノルム、正規化統計を使わない。L0の正規化統計の変化も状態適応として記録し、「重み固定」を「内部状態が全く変わらない」と解釈しない。

## 感覚予測と再帰状態

L2・L3は、今のz_tと自己行動a_tのone-hotを予測ヘッドへ入力し、次の実感覚を予測する。予測ヘッドの実入力次元は`h + 行動one-hot次元`とする。図の線形予測ヘッドはこの連結後に適用する。

対象はRGB/255、固定の音変換、許可したエネルギー/100である。音は各記号の強度を`log1p`で固定変換する。体内感覚なしの条件では、エネルギーを予測対象にも評価基底にも入れない。意味ラベル、正解操作、出生数、生存成績は対象にしない。

予測損失は、視覚・音・体内感覚それぞれの成分内MSEを求め、存在する感覚種の間で平均する。画像の画素数だけで他の感覚の寄与が消えないようにする。学習用にraw遷移を再訪しない。一遷移を一度更新したら破棄する。

v0のBPTT長は1とする。GRUへの前時刻のhidden stateを毎判断でdetachし、現在の観測から現在のhidden stateを作る計算だけに勾配を流す。hiddenの数値は生涯中保持する。長期の勾配伝播は別条件として追加できるが、暗黙に全生涯のグラフを保存しない。

死亡前の最後の身体・位置から最終観測を作成し、死亡した旧個体IDの遷移へ保存する。最終観測を得られない異常は記録し、予測損失だけを省略する。出生した子の観測を親や死亡枠の次感覚へ使わない。

## L3の内的評価

評価器は`r_raw=tanh(w·phi)`。wは出生時の遺伝情報で、生涯中固定する。phiの順序は、許可されたエネルギー差/100、RGB平均の前後差3成分、次観測の記号別受信強度の固定変換、今回の自己行動one-hotとする。特徴名と順序を設定へ保存する。体内感覚なしではエネルギー差の成分を0にし、ゲーム内部の真のエネルギーを評価器だけに渡さない。

wの創始値は標準偏差0.01の符号付き正規乱数とする。評価器を自分のrを増やす勾配で学習しない。予測損失を行動報酬へ足さない。死亡、採食、通信、繁殖のイベントへの固定加点・減点も足さない。

## L3の行動と価値の更新

[Stream-AC v3のAlgorithm 2とStreamingOptimizer](https://arxiv.org/html/2410.14606v3)を参照し、適格度トレースと要素別の更新制御を使う。ただし本案は、感覚予測で変わるGRU特徴、離散の成分別行動、ヘッドだけのRL更新、独自の初期値を使う適用版である。原論文のネットワーク・疎初期化・実験設定の再現とは呼ばず、Stream-Xの性能を保証するものとして扱わない。

政策と価値のパラメータをそれぞれtheta、v、学習入力を`stop_gradient(z_t)`とする。成分別行動の対数確率とエントロピーは全成分の和を使う。通信なし等、設定で単一選択肢になるヘッドの寄与は0である。身体や資源の真の状態に応じたaction maskは使わず、操作の不成立は世界が処理する。

```text
delta = r_scaled + gamma × (1-terminal) × V(z_next) - V(z_t)
e_V   = gamma × lambda × e_V + grad_v V(z_t)
e_pi  = gamma × lambda × e_pi
        + grad_theta [log pi(a_t|z_t) + tau × sign(delta) × H(pi(.|z_t))]

u_V = stop_gradient(delta) × e_V
u_pi = stop_gradient(delta) × e_pi
各ヘッド群について b = max(beta_stream × b, abs(u))
パラメータ += alpha × u / (b + epsilon)
```

すべて要素別・個体別に保持する。deltaと次状態の価値は学習対象からdetachし、評価器、予測コア、他個体へ逆伝播しない。actorとcriticは同じ更新前スナップショットでdeltaとトレースを計算してから更新する。死亡はbootstrapを0にする終端であり、固定の死亡罰ではない。観測期間の終了や保存停止は死亡ではなく打切りとし、終端フラグを立てない。

L3のRLヘッドはAdamを使わない。Adamを使うのはL2・L3の感覚予測部分である。この分離により、同じパラメータに二つのoptimizerが暗黙に更新を加える状態を避ける。

## 正規化と一遷移の処理順

観測は固定変換後の連続感覚成分だけを、個体専用のWelford平均・分散で正規化する。自己行動one-hotは正規化しない。履歴が2観測未満なら平均0・標準偏差1、以後は標準偏差の下限0.01を使い、ネット入力は[-5,5]へclipする。統計は過去の自分の観測だけから作る。

内的報酬は`U=gamma U+r_raw`の個体別履歴の標準偏差で割り、平均は引かない。2件未満は尺度1、以後は標準偏差の下限0.01を使う。報酬の符号を保つ。raw評価器の入力にはこの学習用の可変正規化を使わない。

1. 現在の個体専用統計で観測o_tを変換し、detachした前hiddenからz_tを作って行動を出す。
2. 世界が全行動を同時に解決し、旧個体IDに対応するo_next、終端、自己操作結果を返す。
3. 同じ感覚コア・観測正規化スナップショットでbootstrap用z_nextを作る。raw感覚からr_rawを計算して保存し、報酬尺度を更新する。
4. L3のdelta、トレース、ヘッド更新を計算する。L1は局所更新、L2・L3は一度の予測更新を行う。対象パラメータは上表のとおり分離する。
5. o_tを観測統計へ一度だけ追加する。z_nextを統計へ先に足したり、次tickに同じ観測を重複集計したりしない。
6. hidden_tの数値をdetachして保持する。次tickのhiddenは新しい重みでo_nextから作り直す。今回bootstrap用に計算したhiddenを二重に進めない。

死亡個体の最終更新を済ませてから、その枠を新生個体へ再利用する。世界内の出生と処理待ちの区別はイベントIDで保持し、子の初行動は次tickとする。

| 予測勾配のL2ノルム上限 | 1.0 | 個体単位でclip。個体数で学習率が変わらないよう損失を集計 |

## 個体枠とoptimizer状態

個体別に、出生ID、遺伝基底、生涯重み、hidden、局所可塑状態、観測・報酬統計、U、Adamのm・v・実更新回数、RLのe_pi・e_V・bを保持する。Adamの回数はoptimizer群ごとの個体軸を持つ整数で、実際にその群を更新したときだけ増やす。

Adamでは各個体iに`m_hat_i=m_i/(1-beta1^t_i)`、`v_hat_i=v_i/(1-beta2^t_i)`を使う。全個体を積んだ一つのParameterに通常のAdamをそのまま適用する実装は使わず、個体別tを持つ関数型更新、または独立optimizerを基準実装とする。通常の独立Adamと同じ勾配列で一致することを確認してからベクトル化する。

出生では指定した遺伝情報だけから重みを作り、hidden、局所可塑状態、勾配、Adamのm・v・t、トレース、b、U、正規化の件数・平均・分散、前行動、終端フラグ、旧遷移をすべて初期化する。親のoptimizerや学習済み重みは継がない。別条件の[セッション反復実験](../experiments/2026-10-11-session-inheritance/results.md)では、セッション境界で獲得モデルを遺伝基底へ移し、入力校正の観測統計もその基底に付随させる。世界内の子はその固定された出生時の校正を継ぎ、生涯中の追加統計は継がない。従来のゼロ校正基底では上記の初期化と一致する。死亡・未使用の枠は重みだけでなく全学習状態の更新を止める。損失を0にするだけでモーメント減衰やweight decayが走る実装にしない。

保存・再開ではこれらすべてと乱数状態を復元する。同じ枠番号に別個体が生まれても、古い履歴を受け継がないことを検証する。

## 実装確認で通す条件

- 別々のoptimizerとベクトル化版へ同じ個体別勾配列を与え、時刻の異なる出生・死亡・無更新を含めて重みと状態が一致する。
- 一個体の勾配だけ変えても、他個体の更新量、正規化、カウンタは変わらない。
- 非活動枠を任意の回数stepしても重み・状態が変わらず、再利用直後は新規に作った個体と一致する。
- L3のRL更新で要素別の変化が各alpha以下で、予測更新、遺伝変異、RL更新をログ上で区別できる。
- 固定の合成遷移列を使い、予測損失の減少、deltaとトレースの符号、終端bootstrap、detach範囲を確認する。これは実装検査だけで、主個体の事前学習には使わない。
- 保存再開で学習状態が復元され、NaN・Inf・状態漏れが出た試行を自然な死亡・全滅として集計しない。
