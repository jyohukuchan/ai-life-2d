## 条件付きの推奨構成

モデル担当の選定は、小型CNNと再帰コア、速い可塑的記憶、更新頻度の異なる中長期記憶、変化する内的評価器、行動器、睡眠中の実経験固定を接続する案である。各部分の規模やパラメータ数は固定せず、必要な機能と計算負荷を比較して決める。最初は更新を制限して接続を検証し、自己修正する更新器と生成した夢の選択・学習まで拡張する。予備容量、自己スナップショット、出生時の一時量も計算予算に含める。

この推奨は、自分の感覚予測や記憶の損失を固定の学習目的として許容し、内的スカラーによる行動学習も許容する場合の案である。内的評価器を自分の出す点数で直接最適化せず、局所可塑性と出生時の変化・選抜を分ける。評価信号も教師誤差も使わない可塑性のみの対案は、同じ世界条件で別に検証する。

二親の継承については、独立して学んだネットワークの重みを単純に平均する案を初手にしない。初期推奨は一方の親から対応したネット基底一式を受け継ぎ、双方の少数の学習・可塑性遺伝変数を交差する方式である。両親の獲得技能を融合した子を作る方式とは区別する。自己複製で記憶まで完全にコピーするかも未決定である。

環境担当の推奨は、身体基準の局所画像と音、接触する手元への操作、同時意図の処理、有限資源、寿命、双方の受容による二親繁殖、自己複製を持つ小さな連続世界である。初期から意味を定めない通信路を使えるようにし、狩りと通行・視線に作用する建築を段階的に追加する。具体的な数値は探索用の仮値であり、確定仕様ではない。

## 近縁研究から分かること

[AckleyとLittmanの著者紹介](https://www.cs.unm.edu/~ackley/)が参照するInteractions Between Learning and Evolutionは、自然選択と個体の学習を組み合わせる直接近い研究である。遺伝する評価機構と生涯に変わる行動を分ける発想を、記憶・睡眠の研究と接続する候補になる。繁殖や観測の条件まで今回と一致するわけではない。

[Polyworld原論文](https://shinyverse.org/larryy/Yaeger.ALife3.pdf)には、視覚、Hebbian生涯学習、世界内の繁殖がある。一方、自立した繁殖戦略の成立前に、採食や交配などを評価して個体を補充する試行も記載されている。これを少数のランダムな初期個体から、評価点や補充なしで集団が成立する保証として使わない。

[通信の進化の研究](https://www.nature.com/articles/srep34615)は、意味を決めない通信路という設計に関係する。ただし、絶対座標の入力、接近による自動出生、出生に伴うランダム死亡による固定個体数など、今回とは異なる条件を使う。通信の学習・進化を観察するには、伝送路を設けるだけでなく、受信が行動を変えたかを調べる必要がある。

## 学習を接続する際の条件

[Nested Learning](https://arxiv.org/abs/2512.24695)の自己修正と、[Sleep](https://arxiv.org/abs/2606.03979)の記憶固定・Dreamingを主実験へ取り込む構想を維持する。それぞれについて、採用する機構、変更する目的、簡略化する部分を明記する。

- Nested Learningで生成するvaluesは連想記憶の教師ベクトルであり、行動の報酬とは別である。
- メタ学習された初期状態や大規模なデータによる学習を、事前学習なしの個体へ無条件に置き換えない。
- Sleepの原方式は教師との一致度や課題成績の改善を評価に使う。今回の条件で何を評価するかは別途定義する。
- 生存・出生・死亡による非勾配の選抜は、生涯内の各更新に使う勾配を直接供給しない。
- 学習する表現を内的評価に使う場合は、環境の変化と表現更新による評価の変化を区別する。

自己教師ありの予測目的を許容する案と、評価信号を使わない局所可塑性の案は、異なる実験条件として比較する。記憶の初期確認だけを主実験の目的へ置き換えず、内的評価、繁殖、通信まで接続するための段階として扱う。

## 環境と計算の共通条件

初期個体数と、繁殖後の最大個体数は別に定める。計算容量の都合で既存個体を死亡させると、それ自体が選抜条件になる。出生制限を使う場合も、拒否された出生と上限に達した時間を記録し、上限の変更で結果が変わるかを調べる。

個体の視覚・聴覚と、人間向けの表示を分ける。表示を止めて高速化しても、個体への観測を省略したり、真の座標や物体ラベルへ置き換えたりしない。実験内時間と計算の実時間も分け、処理順序やGPU待ち時間だけで個体の寿命や繁殖機会が変わらないようにする。

同じGPUで処理をまとめても、個体の重み、記憶、経験、勾配を共有しない。二親による出生と自己複製では、継承する範囲を定め、出生後の学習を独立に保つ。

N個体を一つの世界で動かした結果は、N回の独立した実験とは扱わない。世界や初期状態の乱数を変えた試行を比較し、通信や睡眠を停止する対照は、観測や計算予算をそろえて評価する。具体的な試行数と速度の目標は、実測後に決める。

## 採用前に決める境界

- 予測や記憶の自己教師あり目的を、固定した学習機構として許容するか。
- 内的評価の生涯内の変化と世代間の変化を、それぞれ何で駆動するか。
- 二親の子と自己コピーに、重み、評価機構、学習則、記憶のどこまでを継承するか。
- 繁殖方式、通信、睡眠、狩り、建築のコストと成立条件に、何を先天的なルールとして入れるか。
- 感覚の形式、個体数上限、全滅時の再開、結果を判断する比較条件。

これらの選択は、調査報告の推奨と根拠を使って具体化する。計算可能性、学習更新の整合性、実際に適応行動が成立するかは、別々に検証する。
