# モデルアーキテクチャ・生涯学習・睡眠・継承の選定

調査日: 2026-10-11。対象: READMEの専用2D人工生命。事前学習なし、個体間の継続的な重み・経験・勾配の共有なし、外的な課題報酬なしを前提とする。本稿は実装前の設計提案であり、GPU実測、環境のインストール、学習実験は実施していない。初期個体数は調査時点で8個体としていたが、2026-10-11に固定条件から外し、実験要因として比較することにした（[実験計画 v0](../experiments/2026-10-11-v0-implementation/plan-v0.md)）。本文に残る8個体・8体の数値は、当時の前提による例示である。

## 1. 主要判断

最初の推奨は、**小型の再帰ネットに、多時間尺度の可塑的記憶、遺伝して変化する内的評価器、世界内の睡眠と実経験の固定を接続する構成**である。Nested LearningとSleepの全機構を最初から縮小再現できたとは呼ばず、自己修正とDreamingまで含む到達構成を別に定義する。

推奨には次の条件がある。

- **自己教師ありの感覚予測・記憶損失を許容する場合**: 個体の自分だけの経験で表現、記憶、更新則、睡眠データの選び方を学習する。行動の内的評価の内容は、予測損失そのものに固定せず、別の評価器と可塑性・継承で変化させる。
- **スカラーの内的報酬も許容する場合**: 行動の生涯更新には内的評価器の出力だけを使うactor–criticを用いる。採集・生存・出生などの外的加点は加えない。これは内部にRLを含む人工生命であり、「RLを全く使わない」構成ではない。
- **上記の目的や内的報酬を許容しない場合**: 同じ身体・感覚・繁殖ルールに、報酬も教師誤差も渡さない局所可塑性を置く対案を主条件にする。実装は可能だが、少数のランダム個体から有用な更新則や生存行動が成立するという実証はない。

この三点はユーザーの未決定事項である。以下で条件付き案を具体化しても、採用済みとは扱わない。

## 2. 原論文が供給するもの・供給しないもの

### Nested Learning / Hope

NLは、異なる更新頻度の最適化過程として記憶と更新則を表す。自己参照モジュールの「values」は連想記憶の更新対象であり、「何を良いとするか」という行動報酬ではない。§8.1はメモリ初期状態を系列・文脈間でメタ学習し、その必要性を明記する。したがって、ランダム初期状態へ内側更新だけを移せば有用な自己修正が始まる、とは結論できない。なお、NL全体を「必ず事前学習済みLLMが必要」とするのも過剰であり、初期状態や更新器を何の目的で学習するかが問題である。[NL本文 §7–9](https://arxiv.org/html/2512.24695v1)

### Language Models Need Sleep

確認した版は2026-07-10のv2。Knowledge Seedingは拡張した低頻度記憶への蒸留を含む。実装例の模倣学習は固定意味評価器と文字列一致を使い、Dreamingは候補データで学習した後の下流評価指標τの改善を報酬にする。実験には既存の言語モデルが使われる。「人間の逐次教師なし」と、評価信号・既存能力なしは同じではない。今回移すのは記憶固定と自己生成経験の再処理であり、意味評価器や課題正答報酬は移さない。[Sleep本文 §3–4](https://arxiv.org/html/2606.03979v2)

### 報酬なしの生涯可塑性・内的評価の進化

EPANNは生涯可塑性と進化を組み合わせる枠組みを整理する。[Born to Learn](https://arxiv.org/abs/1703.10371) は設計領域の参照であり、本条件の成功保証ではない。

Najarro & Risiはランダム重みからの生涯Hebbian適応を示すが、可塑性則は外側の課題fitnessで進化探索している。生涯中に報酬を見ないことは、学習則も無評価で獲得されたことを意味しない。最新v5でも視覚課題は約9万重み・外側集団200であり、少数の初期個体・世界内出生へ直接外挿はできない。モデル規模も別途選定する。v3でbug修正と再実験、v4/v5で式・初期値の修正があるため、初期版の対角パターンや性能値を根拠にしない。[Meta-Learning through Hebbian Plasticity in Random Networks v5, §3–4](https://arxiv.org/html/2007.02686v5)、[改訂履歴](https://arxiv.org/abs/2007.02686)

Polyworldは視覚・Hebbian生涯更新・出生を接続した近縁例。ただし原著は、自立繁殖までの補助として、採食・交配・移動などのad hoc fitnessと最低個体数補充を使う試行を記す。健康エネルギーも直接入力する。今回はその補助や感覚入力を無断で導入しない。[Polyworld原著 §3, §7](https://shinyverse.org/larryy/Yaeger.ALife3.pdf)

Singhらは内的報酬と世代のfitnessを区別する枠組みを示す。ただし実験は明示fitnessによる報酬関数探索である。[Intrinsically Motivated Reinforcement Learning: An Evolutionary Perspective](https://www.henniglab.org/assets/pdf/canon/Singh2010.pdf) Zhengらの報酬メタ学習も外側に外的報酬があるため、そのまま採用しない。[What Can Learned Intrinsic Rewards Capture?](https://proceedings.mlr.press/v119/zheng20b/zheng20b.pdf)

より直接近縁なのはAckley & LittmanのERLである。遺伝する評価ネットが生涯の行動学習信号を供給し、遺伝子は獲得重みで書き戻されない。相手がいない場合の無性繁殖も扱う。ただし評価器は生涯固定で、自動的な出生・相手選択や物体型/身体数値の入力を使うため、そのままでは今回の選択・感覚・可変評価の条件に合わない。[Interactions Between Learning and Evolution, §2–3](https://gwern.net/doc/reinforcement-learning/meta-learning/1992-ackley.pdf)

補足として、2026-09-27公開のVisionHOPEは自己参照更新の不安定性を扱う。これは画像内の更新とImageNet等での外側学習であり、世界内の生涯学習実証ではない。安定化の検討材料に留め、最初の視覚エンコーダには採用しない。[VisionHOPE §2–3](https://arxiv.org/html/2609.33325v1)

## 4. 構成要素とモデル規模の選定

モデルのパラメータ数に固定の目標や上限は設けない。以下は機能を接続するための設計枠であり、幅、層数、記憶ブロック数、更新器の規模は、研究上必要な表現力と実測した計算負荷から選ぶ。特定の規模を前提にした割当表は使わない。

| 機能 | 規模を決める主な変数 | 役割 |
| --- | --- | --- |
| 視覚CNN + 音エンコーダ | 観測解像度、音の形式、特徴次元、層数 | 局所感覚を処理する |
| 融合・再帰コア | 入力次元、隠れ次元、再帰層数 | 前の自己操作と感覚の履歴を保持する |
| 中期・長期の残差MLP記憶 | 記憶の段数、各ブロックの幅、更新頻度 | 異なる時間尺度の知識を保持する |
| 速い連想記憶と更新調節器 | key/value次元、記憶行列の大きさ、更新器の構造 | 活動中に記憶を更新する |
| 次感覚予測・再構成デコーダ | 予測対象の解像度、出力分布、予測時間幅 | 実感覚を学習対象にして表現の崩壊を防ぐ |
| 内的評価器と局所可塑性 | 評価器の幅、可塑接続の範囲、遺伝変数 | 行動評価とその変化を表す |
| 行動器と内的return予測器 | 身体操作の形式、各出力の次元、層数 | 移動・通信・睡眠・繁殖などを選ぶ |
| 睡眠とDreamingの追加機構 | 記憶の予備容量、生成器、候補数、仮更新範囲 | 記憶固定と自己生成データの利用を行う |

通常の学習対象パラメータ、動的fast weight、hidden state、可塑性trace、経験バッファを区別して集計する。F0を別の学習可能テンソルにする場合はパラメータとして数え、時系列ごとのFの中間コピーは状態メモリとして計上する。総パラメータ数だけでなく、1判断・1更新・1睡眠・1出生当たりの時間とメモリも比較する。

睡眠時の凍結した自己スナップショット、出生時のコピー、遺伝子として残す出生重み、常設する教師も計算予算に含める。睡眠による拡張の上限や予備容量は、モデルの固定パラメータ条件とは別に、実測した容量から定める。本案は必須の常設EMA教師を置かない。

48×48 RGBの身体中心の局所画像を実装試験用の入力候補とする。ただし視野・遮蔽・色・回転・音の有無は感覚仕様の決定事項であり、本稿で固定しない。真座標、全体マップ、物体ID/意味ラベル、相手の内部状態、子孫数、採集成功フラグは入力しない。前に出した自分の操作は個体の履歴として保持できる。

身体の空腹・疲労・損傷を直接数値入力する案は感覚条件の変更である。まずは合意された視覚/音の身体感覚表現だけを受け取る。恒常性の報酬を採用する場合も、その感覚と基準値を別途定義する必要がある。

## 5. 統合した接続と各更新の定義

以降は原論文の式の転載ではなく、本実験向けの候補設計である。個体iの状態はすべて個別に保持し、添字iを省略する。

```text
局所感覚 x_t + 前の自己操作 a_(t-1)
        ↓
感覚表現 z_t → 再帰状態 h_t ← 速い記憶 F_t / 中期・長期記憶 θ
        │                  │
        │                  ├→ 行動分布 → 移動・操作・発信・睡眠・繁殖の試行
        │                  │                            ↓
        └→ 内的評価器 R_(g,P) ← 自分の次感覚 x_(t+1) / 操作結果の感覚
                       │
                       └→ r_int → 行動器/return予測器の生涯更新

自分の経験 D → 覚醒中の記憶更新 / 睡眠時の安定記憶への固定
                    ↑                 ↑
           到達構成: 更新器の     到達構成: 自己生成データと仮更新
              オンライン学習        → 未学習の実経験で評価

出生時のみ: 親の遺伝情報 g → 交差/変異 → 子の初期状態
世界内の出生・死亡 → 遺伝子の残り方が変わる。個体への加点は発生しない
```

### 5.1 感覚と記憶を学ぶ信号

自己教師あり目的を許容する条件では、実際に次に経験した局所感覚を対象にする。

\[
L_{sens}=-\log p_\theta(x_{t+1}\mid h_t,a_t,F_t)
        +\lambda_{rec}L_{rec}(x_t,\hat x_t).
\]

対象は観測した生画像・音であり、意味ラベルや正解行動ではない。出力を縮小解像度にする場合は、観測入力の縮小と区別して記録する。潜在表現同士の一致だけにすると、表現が定数に崩壊しても低損失になるため、最初は生感覚の再構成/予測を残す。低誤差の無動作を好むような行動目的には直接しない。

初期の速い記憶は、正規化keyに対する制限付きdelta書込みとする。

\[
F_{t+1}=\Pi_C\{\rho F_t+\eta(v_t-F_t k_t)k_t^\top\},\quad
L_{write}=\tfrac12\|F_tk_t-v_t\|^2.
\]

ここでvは感覚履歴から作る記憶対象、Πはノルム上限、ρ・ηは有界の保持率・更新率である。初期は値の生成と更新式を固定し、そのkey/query/value投影を自分の感覚予測で学習する。**これは制限したNL風メモリであり、自己参照更新器を学び終えたHopeではない。** 内側の自己一致だけでは役に立つ表現を選べないため、外側の実感覚の損失との経路を維持する。

### 5.2 内的評価器が実際に変化する方法

評価器の遺伝情報をg、可塑状態をPとする。最初の案は、固定縮小した局所の生感覚と自己操作履歴を主入力にする。未知の物体の意味を与えず、学習するエンコーダに評価内容が全面依存しないようにする。

\[
r_t^{int}=r_{max}\tanh R_{g,P}(b_t,a_t,b_{t+1},\text{private history}).
\]

bはその個体が受け取った感覚の固定変換である。新しさ・予測誤差・学習進捗などを追加入力する比較は可能だが、それらへの係数を必ず正にして主報酬を固定する案とは分ける。rの振幅・分散を有界にするのは数値安定化であり、採食等を良いとする点数ではない。

評価器の生涯可塑性には、たとえば次の局所則を使える。

\[
P_{t+1}=\Pi_C\{(1-\lambda)P_t+
 \eta m_t\left(y_tx_t^\top-\operatorname{diag}(y_t^2)P_t\right)\}.
\]

この式のx/yは評価器内部のpre/post活動、mは同じ個体内の有界な調節信号である。η・λ・調節器の少数係数は遺伝する。これは局所相関と安定化による変化であり、生存を改善する勾配ではない。符号や時間尺度も出生時変異の対象にできる。初期は接続ごとの5倍の遺伝子を持たせず、16–128程度の群別制御変数から始める。

この少数遺伝子には、可塑性の強さだけでなく、**固定感覚基底に対する符号付きの評価係数**も含める。評価器の内容が世代で変わる経路を残すためである。基底には縮小画像の画素群や自己操作の固定した履歴変換を使い、意味ラベルは使わない。学習で意味が動く隠れユニットへの評価係数は、そのユニットと同じ提供親から一式で継承し、他親の同添字の係数へ無条件で差し替えない。

評価器に「自分の出したrを増やす」勾配を流さない。そうすると身体への適応を経ずに常に高い値を出す解がある。行動学習から評価器・評価用入力へはstop-gradientを入れる。評価器は、**生涯では局所可塑性、世代間では交差・変異と出生/死亡**によって変化する。その変化が有用かは実験結果であり、局所則を置いただけでは保証されない。

この選定は、価値観の生涯変化を最適化済みの機構に見せないためである。代わりに「評価器のパラメータを学習する」と呼べるメタ勾配を使うなら、外側で何を改善するかが必要になる。感覚予測改善を使うこともできるが、そのときは予測に役立つ評価を人間が選んだ条件であり、評価内容が無目的に自発獲得されたことにはならない。

### 5.3 行動の生涯更新

内的スカラーを許容する条件では、行動器πと内的return予測Vを次で更新する。

\[
\delta_t=\operatorname{sg}(r_t^{int})+
 \gamma V(h_{t+1})-V(h_t),\qquad
L_\pi=-\log\pi(a_t\mid h_t)\operatorname{sg}(A_t)-\beta H(\pi),
\]

\[
L_V=(V(h_t)-\operatorname{sg}(G_t^{int}))^2.
\]

小さなon-policyのactor–criticから始め、初期32経験程度のrolloutを候補にする。Vは未来の内的rの予測器であり、rを定義する評価器とは別である。エントロピー項・行動の確率性も探索の設計上の先入観なので記録する。

移動、身体操作、発信、睡眠の開始/終了、二親繁殖の試行、自己複製の試行、何もしない操作を同じ行動出力に含める。繁殖の可否は身体・距離・同意・資源・世界上限のルールが判定するが、その判定フラグを追加の報酬や特権入力にしない。通信は無意味の信号として身体から出し、相手には合意した感覚経路で届く。人間の文字トークナイザ・語彙埋め込み・会話教師を置かない。

### 5.4 更新順序と評価の非定常性

推奨の初期手順は、32経験のrollout中に感覚エンコーダと評価器基底の重みを固定し、遷移の内的rを計算・保存してから行動器を更新する。評価器の局所可塑性は活動traceを集め、rollout境界で適用する。速い記憶と再帰状態は行動中にも更新する。

潜在表現の前後差を評価に使う場合は、両側を**同じエンコーダ・評価器スナップショット**で計算する。学習進捗を入力するなら、同じ実経験集合・同じ入力表現に対する仮更新前後の損失差を用いる。学習後に古いrを再定義しない。そうしないと、世界で良い変化が起きたのか、内部表現の座標が動いただけなのか分からなくなる。

## 6. 実装開始用の睡眠と、到達構成

### 6.1 最初の睡眠: 世界内休止と記憶固定

睡眠は身体の状態として出力し、世界内では移動・採集等を休止する。睡眠中も世界の時間・資源消費・接触は同じ規則で進む。GPU処理が遅い個体だけ多く老化させない。

内部処理は、自己専用の最近経験＋過去の一様reservoirを再処理する。睡眠前の自分を一時凍結し、速い記憶を持つ教師の予測を、速い状態を初期化した学生の安定記憶へ移す。

\[
L_{sleep}=L_{sens}(D_{recent}\cup D_{old})+
 \lambda_{distill}D(p_{self\,before}^{fast}\|p_{self\,after}^{slow})
 +\lambda_{anchor}L_{sens}(D_{anchor}).
\]

教師は同一個体の凍結コピーであり、他個体・事前学習モデル・意味評価器ではない。蒸留対象は未来感覚の予測分布等とし、実感覚の損失も残す。間違った自己予測だけの反復を避ける。初期は長期記憶だけを更新し、行動器は夢の中では更新しない。睡眠による追加容量と更新回数に計算予算を設ける。具体的な予備容量や拡張上限は、選定するモデルと実測した負荷から決める。

この段階はSleepの記憶固定を参考にするが、原論文の一般化蒸留とDreaming全体の再現ではない。睡眠開始条件を評価するため、学習成立確認用には定期睡眠の比較条件を置き、その後に同じコスト下で自発的な睡眠操作と比較する。定期睡眠を選んだ個体の行動として数えない。

### 6.2 到達構成A: 自己修正する更新器

開始案で更新経路と忘却を測れた後、速い記憶の更新器Uφを有界な自己修正モジュールにする。入力はその個体の現在の記憶、感覚表現、局所誤差、直前の更新履歴。key/value・保持率・更新率も履歴により変わる。

外側の目的を曖昧にしない。

\[
F_{t+1}=U_\phi(F_t,z_t,a_t,z_{t+1}),\quad
J_{meta}(\phi,F_0)=\sum_{u\in\text{later actual experience}}
L_{sens}(x_u;\theta,F_u).
\]

同じ個体の後続実経験で、直前の更新が感覚予測を改善したかを評価する。16程度の更新をtruncated unrollし、まず小型の更新率/保持率調節器だけにメタ勾配を流す。高速書込み・メタ更新・長期記憶更新を同時に増やさない。

F0や更新器の初期状態も個体内で得た実経験区間の入口状態としてメタ学習できる。ただしこれは実験開始後のオンラインメタ学習であり、開始時に有用なF0が存在する保証ではない。世代間で何を継ぐかは別の継承条件にする。記憶初期値を変えても、現在の経験状態を無条件で消去しない。

### 6.3 到達構成B: 評価信号を明示したDreaming

自己教師あり目的を許容する条件に限り、以下の実験がつながる。

1. 個体の予測モデルが、自分の実経験をseedに短い感覚/潜在軌跡を生成する。生成器は行動列・開始経験・再構成の組合せ等を選ぶ。初期は実経験の選択・再組合せだけに制限し、後に生成へ進む。
2. 候補dreamごとに小型adapter等の仮コピーを逐次更新する。仮更新には生成データの感覚/記憶目的を使う。
3. 学習に使っていない自分の実経験Dvalと過去の保持用経験Danchorで、仮更新前後を比較する。
4. 次の信号でdreamの選択/生成器を更新する。

\[
J_{dream}=L_{sens}(D_{val};\theta)
-L_{sens}(D_{val};\theta')
-\lambda\max\{0,L_{sens}(D_{anchor};\theta')-L_{sens}(D_{anchor};\theta)\}.
\]

候補を出す分布qφをREINFORCE等で更新するなら、Jdreamをbaselineで中心化し、`-sg(Jdream-baseline) log qφ(dream)`を最小化する。予測モデルや評価器への勝手な逆伝播はしない。候補の仮更新・評価を並列大量コピーせず逐次にし、実コピーとoptimizer stateの予算も記録する。

**ここでτに相当するのは自分の実感覚への汎化であり、生存・繁殖・協調の点数ではない。しかし人間が選んだ外側の目的である。** 生成器が値判断を自由に発見したという証拠にはならない。到達構成では、感覚/記憶更新器の自己修正、睡眠固定、dream生成器の学習、内的評価の可塑性が一つの個体内に共存するが、各々の評価基準を混ぜない。

Dvalは未来の特権情報ではなく、観測済みだがその候補の更新に未使用の実経験である。時間順の保留と更新回数上限を設け、繰り返し選択による過適合を監視する。sleep中に取得していない世界情報を夢の正解にしない。未学習のモデルの夢は有用とは限らないので、実経験だけの再処理に対してheld-outの予測改善が出ない段階では生成を有効にしない。

夢で行動器を更新することは初期推奨に含めない。予測が改善したことだけでは、内的評価に沿う行動が世界で改善したとは言えず、モデルの誤りを利用する危険もある。追加する場合は別の比較と評価信号が必要になる。

### 6.4 完全rewardless局所可塑性を選ぶ場合

感覚予測損失、actor–critic、誤差蒸留、Jdreamを全て外す。感覚→再帰活動→身体操作のネットと、群別の有界Hebbian/Oja型可塑性、内部調節器を接続する。睡眠は保存活動の再生と低速の同じ局所則だけにする。個体は生涯の教師誤差も報酬も受け取らず、更新則の系統変化は出生時交差・変異と世界内の出生/死亡だけで起こる。

この方式にも、正規化、局所相関、結線、ノイズ等の設計上の偏りはある。「rewardless」は目的も帰納バイアスもゼロという意味ではない。とくにこの条件には、原Sleepのdreamを改善で選ぶτの代替が存在しない。自発的再生を「夢」と呼ぶことはできても、自己改善するDreamingが成立すると断定できない。全滅・発達停滞をそのまま記録する対案である。

## 7. 生涯内と世代間の時間尺度

数値は最初に試す更新周期の候補であり、環境の実時間や生理の決定ではない。

| 時間尺度 | 入力 | 更新・目的 | 継承 |
| --- | --- | --- | --- |
| 1判断 | 自分の局所感覚・前の操作 | 再帰状態、速い連想記憶。条件付きLwrite | 原則リセット |
| 32経験程度 | 自分のrollout・保存した内的r | 行動器/return予測、感覚予測、評価器の局所可塑性 | 生涯状態は原則リセット |
| 128–512経験程度 | 自分の短い経験系列 | 中期記憶の更新、到達構成の更新器メタ学習 | 継承条件で指定 |
| 睡眠イベント | 自分の実経験・自己スナップショット | 安定記憶固定、到達構成のdream評価 | 継承条件で指定 |
| 出生イベント | 合意した親の遺伝情報のみ | 交差・変異、初期重み/可塑性/容量の生成 | 子へ一度だけ渡す |
| 長い系統の時間 | 世界内の出生/死亡 | **非勾配の選抜**。系統の個体数・遺伝子頻度が変わる | 増えた系統の遺伝情報が残る |

自然選抜は、死んだ個体の各操作に逆伝播する信号ではない。子が出生しなければ遺伝子の複製は起こらず、全個体が死ねば試行終了になる。遺伝情報の変異方向を生存統計の勾配で選んだり、成功個体だけ管理側が補充する場合は、主条件とは別の外側探索となる。

生涯では評価器の可塑状態が変わっても、遺伝する基底gへ自動で書き戻さない基準をまず用意する。獲得重みの継承は明示した別条件とする。継承が弱ければ世代ごとに学び直し、強ければ現在の環境への過適応や異なる身体での不整合を持ち越す。

## 8. 二親の継承と自己複製

### 単純平均を最初に使わない理由

独立ネットの隠れユニットは同じ添字でも同じ特徴を表すとは限らない。たとえば隠れユニットを入れ替え、次の層も対応して入れ替えれば同じ関数だが、別の配列のまま平均するとその機能を壊せる。再帰状態・key/value・評価器の表現も共適応するため、同じ層形状だけでは十分でない。[Git Re-Basin](https://arxiv.org/html/2209.04836v1)

共通の事前学習重みからのfine-tuningで平均が成功するModel soupsの条件も、今回の独立ランダム個体と異なる。[Model soups](https://arxiv.org/abs/2203.05482)

### 初期推奨の出生処理

二親では、**大きい初期ネットの一式を一方の親から選び、双方の小さな同種の学習・可塑性遺伝子を交差する**。ネット一式の提供親は出生ごとに等確率で選ぶ。もう一方も更新速度・可塑性・評価器の調節・睡眠制御等に寄与する。これは両親の獲得知識の融合ではなく、二親から性質を受け継ぐ最初の定義である。

1. 親の出生時genotypeと、生涯で獲得したphenotypeを別に保存する。
2. ネット基底と、その表現に結びつく評価器基底は同じ提供親から一式で継承する。最初の基準は親の出生時基底を使い、生涯獲得重みを戻さない。
3. 対応が明確な16–128の群別可塑性・時間尺度等の遺伝変数は両親から交差する。変異は小さい有界な変数を中心にし、ネットワーク全重みの無制限な交差はしない。
4. 子のhidden state、速い記憶、経験、勾配、optimizer state、評価器の可塑状態は初期化する。出生後は完全に独立する。
5. 保存時には、基底の提供親、遺伝変数ごとの出所、変異、継承対象、出生時hashを記録する。

自己複製では同じスキーマの遺伝情報を一親から渡す。「無変異の遺伝子コピー」「変異ありの子」「学習済み重みまで含めるコピー」「経験/記憶まで含めるコピー」を別条件として区別する。同じモデルの自動リスポーンにはしない。

評価器基底と学習中表現を別親から無条件に差し替えると、好みを継いだのでなく特徴の対応を失っただけになり得る。小遺伝子交差にも相互作用はあるので、出生直後の数値安定性と挙動を記録し、適応保証とはしない。

### 後の比較候補

| 継承候補 | 利点 | 未解決点 |
| --- | --- | --- |
| 初期推奨: 基底一式 + 少数遺伝変数 | 表現の破壊を抑え、両親の寄与を追える | 両親の学習済み技能を融合しない |
| 対応する小型adapter/遺伝モジュールを交差 | 交差対象を制限できる | 基底の対応が必要。独立表現へ同じadapterを挿せない |
| ユニット整列後の重み交差/平均 | 配列の対称性へ対処できる | 動的記憶・評価・再帰の一致や機能保存は保証されない |
| 出生時だけ二親から学生へ蒸留 | 重みの対応を要求しない | どの経験を共有するか、相反する行動/評価を何で選ぶか、出生時学習コストが必要 |
| 獲得した安定重みを一式継承 | 生涯獲得知識を残せる | Lamarck型条件。世代選抜と学習の寄与を分ける必要 |

出生時蒸留で親の経験を渡す場合は、出生時の明示的継承として扱う。活動中の共有は禁止のままにする。子が一方の「良い答え」を選べる外部教師があると仮定しない。

## 9. 計算資源予算: 概算と未測定を分ける

ハードウェアはREADME記載の3995WX 64コア、RAM約110 GiB、V620 32GB×2、R9700 32GB×1。GPUのROCm/PyTorch互換性、精度対応、実効速度、GPU間転送は今回未確認である。標準Pythonのtorchが前回CPU版だったため、GPUを利用できるという前提で試行時間を約束しない。

| 項目 | 机上概算 |
| --- | --- |
| P個のFP32重み | 4P byte/個体。Pは選定するモデルのパラメータ数 |
| 全P個をFP32で学習する場合の重み + 勾配 + Adamの2モーメント | 単純計算で16P byte/個体、N体で16NP byte（8体なら128P byte）。活性・一時領域・状態・コピーは別途加算 |
| 出生時基底・睡眠教師のFP32コピー | 全重みを複製するなら、それぞれ4P byte/個体。教師はoptimizer不要。コピー数と複製範囲を明示 |
| 通常の短系列学習の一時量 | モデル構造、系列長、同時系列数、精度に依存するため、候補ごとに実測する |
| 自己修正器のunroll/仮更新 | 更新対象の数、unroll長、候補コピー数に依存する。状態保存と仮更新を含むピークを実測する |
| 48×48 RGBをuint8で保存 | 6,912 byte/観測。16,384観測で108 MiB/個体、8体で864 MiB。音・履歴等込みの約8 KiB/経験なら約1 GiB/8体 |
| 65,536経験まで増やす場合 | 約512 MiB/個体、約4 GiB/8体を8 KiB/経験で見積もる。画像をfloat32保存すると画像部分は4倍 |

混合精度は低精度重み以外にmaster重みやoptimizer stateを持つ場合があり、「全部が半分になる」と見積もらない。正確なモデル、同時系列数、カーネル実装が決まるまで総VRAMや毎秒経験数は確定できない。

最初の実行配置は**1枚で独立個体を数体処理し、個体ごとの重みを保ったまま学習時間を交代させる**候補とする。3枚のVRAMを一つの96GB装置として扱わない。重みの異なる個体に通常の共有重みbatchを使わず、個体軸の独立演算または逐次処理にする。分散学習・全GPUの勾配同期は不要である。

出生上限を満たすメモリが必要であり、初期個体数だけの計算で最大集団を決めない。個体当たりの実測ピーク、同時学習数、環境・推論・教師・出生処理を含めて最大個体数を決める。モデル規模と集団上限の組合せを比較する。

CPUは世界更新・観測生成・経験保存・圧縮・チェックポイントを担当できるが、64コアの全てが有効に使えるとは仮定しない。各個体の小さい行列計算、Python呼出し、GPUへの転送が律速になり得る。

睡眠計算は初期には1睡眠イベント当たりのminibatch数に上限を置く。到達Dreamingは候補2–4、仮更新1–4回程度から試し、候補コピーは逐次再利用する。この数値はコストを制限する実装用の候補であり、生物学的睡眠モデルではない。

必要な初回測定は、世界tick/秒、観測生成時間、個体判断/秒、通常更新・睡眠固定・メタunroll・dream仮更新の各時間、RAM/VRAM最大値、出生時一時使用量、保存/再開時間である。比較は世界内時間をそろえる条件と計算量をそろえる条件の両方を記録する。

## 10. 意味のある比較実験

一つの連続世界の見栄えだけで成立を判断しない。**複数の独立世界/seed**を使う。同じ保存点から条件を分岐させた別実行は、共通の履歴を持つ対応あり比較であり、統計的に独立な標本を増やしたとは扱わない。独立標本の単位は元の世界/seedとし、個体や分岐をそのまま標本数に数えない。最初は独立な8–20世界程度のpilotから分散を測り、正式な試行数はそのばらつきで決める。

| 比較 | 揃えるもの | 分かること |
| --- | --- | --- |
| 学習停止 / 固定再帰状態のみ / 局所可塑性 / 条件付き統合案 | 身体・世界・出生・初期感覚・個体数 | 生涯重み更新の効果と単なる再帰記憶を分ける |
| 同じ規模のGRU基準 / 速い記憶追加 / 異なる頻度の記憶 / 自己修正器 | パラメータ枠、経験数、計算量も別途報告 | NL由来の機構が何に寄与したか |
| 睡眠なし / 覚醒中に同量の実経験再処理 / 世界内睡眠で再処理 | 同じ再処理回数と、同じ世界内の活動コスト | 再処理の計算効果と、休止する生態的効果を分ける |
| 実経験のみ / 一様な生成夢 / 学習して選ぶ夢 | 生成・仮更新・評価の総計算量 | 生成そのものと、自己修正する選択の効果 |
| 評価器の局所可塑性を停止 / 有効 | 同じ初期評価器、外的報酬なし | 生涯で評価の内容が変わる効果 |
| 評価器の遺伝変異なし / あり | 出生ルール、人口上限、介入前の系統状態 | 世代変化と生涯変化を分ける |
| 出生時基底のみ / 獲得した安定重みも継ぐ / 速い記憶まで継ぐ | 出生資源、容量、開始世界の条件 | 生涯獲得情報の継承による寄与 |
| 自己複製のみ / 二親のみ / 両方選べる | 方式別資源コストを明示 | 繁殖方式の選択と、ルールによる有利不利 |
| 通信停止 / 信号シャッフル / 送り手入替え | 到達距離、発信コスト、感覚条件 | 信号が受信者へ与える因果効果 |

観察指標は、経験後の行動変化、遅延後の保持、新しい地形への適応、内的評価器の同一入力への出力変化、死亡/出生/系統継続、方式別出生、通信介入の行動差、資源利用、建築の物理的効果。これらを個体の報酬へ戻さない。予測損失の低下だけで生存適応や言語が成立したとは判断しない。

価値観の変化は、時刻の違う評価器を同じ保存感覚集合で比較する。経験が違うだけの比較と、評価写像そのものの変化を分ける。世代適応は、同じ遺伝情報から生まれた子を複数の共通条件に置く別試行で確かめ、生涯の偶然や親の場所・建築物の継承と区別する。

| --- | --- | --- |
| 感覚予測・蒸留・保留経験の目的 | まず許容する条件を一つ設け、完全rewardless対案と比較 | 不許可なら本稿の勾配による自己修正・Dreaming評価は成立しない |
| 内的スカラーと行動RL | 外的加点なしの内的評価器を分離し、局所可塑性と世代変異で変える | 不許可なら局所可塑性のみの行動器へ切替え |
| 固定の恒常性/新しさ/学習進捗 | 主案の固定正報酬にはせず、別比較 | 固定の欲求をどこまで初期条件に含めるか |
| 睡眠 | まず実経験固定、次に生成と仮更新評価 | 開始/終了条件、身体コスト、刺激による覚醒、容量の使い方 |
| 二親継承 | 基底一式は一親、少数の同種遺伝変数は二親から交差 | 両親の獲得知識融合まで要求するか |
| 自己複製 | 遺伝コピーを基準に、学習済み状態コピーを別比較 | 完全複製の範囲と変異 |
| 出生/死亡/集団上限 | 世界内選抜だけを主条件とし、補充しない | 上限時の出生扱いは選抜圧そのものになる |

最大のリスクは、**少数の初期個体が有用な遺伝変異を残す前に全滅すること**である。パラメータ数を増やすだけで探索が容易になるわけではなく、小集団は遺伝的浮動も大きい。生涯予測は世界の規則を覚える手段にはなるが、食べる・生きる・繁殖することの価値を自動的に与えない。ランダムな評価器や可塑性も有用とは限らない。

また、可塑的評価器が行動を学ばせ、変わった行動が感覚分布を変え、その分布が評価器を変えるため、閉ループは不安定になり得る。出力範囲、保持率、更新量、記憶容量の制限と、機構別の停止比較が必要である。制限は数値的に暴走しないためのもので、自然に適応が出る保証ではない。

原論文群の各部品には実証があるが、本条件の組合せ全体は未実証である。したがって本稿の結論は「更新経路を明示した実装可能な研究設計」であり、「ランダムな初期個体の人工生命が成長・通信・繁殖を実現すると確認済み」ではない。

## 12. 一次資料の確認範囲

本文中のリンクは原論文/著者版へのリンク。NLはv1、Sleepはv2のHTML本文を確認した。Hebbianメタ学習は当初v2を読み、最終確認で最新v5の§3–4と改訂履歴を確認・差し替えた。Polyworld・内的報酬メタ学習は本文の外側目的と入力/更新方式を確認した。VisionHOPEは最新の補足候補として扱い、今回の推奨をその性能に依存させていない。

報酬関数と評価器の世代継承については、[Ackley & Littman, Interactions Between Learning and Evolution](https://gwern.net/doc/reinforcement-learning/meta-learning/1992-ackley.pdf) の§2を、別担当が取得した原著PDFのテキストで追加確認した。webでの直接取得はタイムアウトしたが、遺伝評価器、生涯の行動更新、遺伝子への書戻しなし、相手不在時の無性繁殖を原著本文で確認できた。

可塑性を勾配で訓練する代案は、[Differentiable plasticity](https://proceedings.mlr.press/v80/miconi18a.html) が参考になる。ただし同研究の外側課題目的を消しても同じ学習則が獲得できると解釈しない。
