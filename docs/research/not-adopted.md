# v0で採用していない先行研究の手法と再検討候補

更新日：2026年10月11日

[実験計画 v0](../experiments/2026-10-11-v0-implementation/plan-v0.md)に入っていない手法・環境要素を、先行研究との対応、現在の扱い、再検討する条件で整理する。対象は[先行研究調査](prior-research.md)、[モデル調査](architecture-learning.md)、[環境調査](environment-design.md)、[追加レビュー](review-2026-10-11.md)と、直前のv0計画レビューで挙がった事項である。

論文を参考にすることと、その学習方法や世界のルールをそのまま採用することは別である。ここにある「未採用」はv0時点の扱いを指し、研究の有効性を否定したり、将来の候補から一律に外したりする意味ではない。個別の見送り理由が記録されていない候補は、判断保留として扱う。

## 扱いの区分

| 区分 | 意味 |
| --- | --- |
| v1以降へ延期 | v0では外し、後続段階に追加する機能として計画に記載されている。具体的な手法の採用まで決まったとは限らない |
| 原方式は現方針で不採用 | 外的課題報酬、事前学習、特権入力、自動出生など、現在の条件と合わない部分をそのまま使わない |
| 比較候補として保留 | 調査では挙がったが、v0の比較条件には入っていない |
| 部分採用または変更して採用 | 考え方や更新の一部を使うが、原論文の一式とは異なる。具体化待ちか、変更点を定義済みかも区別する |
| 評価用として保留 | 観測者側の測定候補であり、個体の目的や選抜点数には使わない |

## v1以降へ延期した機能

根拠は実験計画v0の§1・§8。v0は感度を調べる探索段階であり、この表の機能の有効性を検証する段階ではない。

| 手法や要素 | 参考研究 | 現在の扱いと再検討点 |
| --- | --- | --- |
| 更新速度の異なる速い記憶と遅い記憶 | [Nested Learning / Hope](https://arxiv.org/abs/2512.24695) | v1以降。v0は通常のGRUが基本。記憶の段数、更新周期、目的関数、計算量を決めて比較する |
| 学習する自己修正器 | Nested Learning、[VisionHOPE](https://arxiv.org/abs/2609.33325) | 記憶・自己更新の拡張候補。v0では更新率等を生成する自己参照機構を選定していない。初期状態を何で学ぶかと安定化が未決定 |
| 世界内の睡眠と実経験の再処理 | [Language Models Need Sleep](https://arxiv.org/abs/2606.03979)、補完学習系理論 | 睡眠機能はv1以降。身体の休止、生理効果、内部の再処理を分けて比較する |
| Knowledge Seedingと記憶固定 | Language Models Need Sleep | 睡眠に接続する候補。原方式の固定意味評価器や文字列一致報酬をそのまま採用せず、個体自身の感覚経験で何を固定するかを定める |
| Dreamingと合成経験の選択 | Language Models Need Sleep | v1以降。生成データによる仮更新を、何の改善で評価するかが未決定。原論文の下流課題成績は主条件へ持ち込まない |
| 生涯中に変わる内的評価器 | EPANN、局所可塑性、モデル調査§5.2 | v1以降。v0のL3は評価係数wを生涯中固定し、世代間で変える。評価器の局所可塑性は未導入 |
| 獲得した重みの継承 | 学習と進化の研究、モデル調査§8 | v1の比較条件。v0は出生時の遺伝情報だけを継ぐ。経験バッファや再帰状態までの完全コピーは、さらに別の未選定条件 |
| 狩り・攻撃・建築・遮蔽・遺体の食料化 | Polyworld、JaxLife、Hide-and-Seek、環境調査 | v1以降。物理的な効用と資源保存を定義し、各要素の追加で感度の結果が変わるか再確認する |
| 脳の規模に応じた代謝費 | Polyworld等の身体・神経活動コスト | v1の要因。v0では実GPU時間やパラメータ数を身体の消費へ変換しない |
| 高解像度視覚と波形の音 | 感覚設計の比較候補 | v1以降。v0はタイルごとのRGBと記号別の受信強度ベクトル。解像度・情報量・計算量の変更を区別する |

## 睡眠方式として残す追加候補

睡眠を延期したことは、次の候補を却下したことを意味しない。いずれもv0に実装する方式としては未選定である。

| 候補 | 参考資料 | 採用前に確認すること |
| --- | --- | --- |
| 睡眠中の局所Hebbian再生 | [Tadros et al. 2022](https://www.nature.com/articles/s41467-022-34938-7) | 睡眠相は局所的な教師なし更新だが、原実験の覚醒相は課題学習を含む。未学習の人工生命へ移した場合の保持・可塑性を別に検証する |
| シナプスの縮小・正規化 | シナプス恒常性仮説。追加レビュー§2.5 | 何をどの程度縮小するか、保持と新しい学習を損なわないかを定義する。単なる縮小を原SleepのDreamingと同一視しない |
| オフライン反復によるfast weightへの書込み | [Lee et al. 2026](https://arxiv.org/abs/2605.26099) | 学習された局所則で文脈を記憶へ反復して書き込む別論文。更新則を今回の経験だけからどう学ぶか、反復数と負荷を比較する |
| 補完学習系としての二つの記憶 | McClelland et al.、Kumaran et al.。追加レビュー§2.5 | 理論的な参照であり、単一の実装済み方式ではない。高速記憶と低速記憶の接続を具体化する |

## 固定の内的目的としては採用していない候補

v0のL3は、固定した感覚基底に対する符号付きの評価係数を遺伝させる。以下の特定量を必ず好む・嫌うように固定する条件は、現行v0の要因表には入っていない。個体へ外的課題報酬を与えないことと、内的な目的を固定しないことも区別する。

| 候補 | 参考研究 | 保留理由と再検討条件 |
| --- | --- | --- |
| 空腹や不足の改善を必ず良いとする恒常性報酬 | [Keramati & Gutkin](https://elifesciences.org/articles/04811) | 望ましい身体状態や好みを人間が固定する条件になる。体内感覚を入力する現在の仕様とは別。固定欲求との比較として追加できる |
| 新しさ・予測誤差を最大化する好奇心 | [ICM / Pathak et al.](https://proceedings.mlr.press/v70/pathak17a.html) | 「未知を好む」目的を固定する。L2の予測損失は行動報酬ではないため、既に採用済みとは扱わない |
| 学習進捗・圧縮の改善を好む報酬 | [OudeyerらのIAC](https://www.pyoudeyer.com/ims.pdf)、[Schmidhuber](https://people.idsia.ch/~juergen/creativity.html) | 何を改善とするかを固定する。単純な予測誤差との違いを測る比較候補 |
| Empowerment | [Klyubinら](https://uhra.herts.ac.uk/id/eprint/282/1/901241.pdf)、[関連する制御研究](https://arxiv.org/abs/2301.00005) | 制御可能性を好む原理と推定器を追加する条件。未選定であり、固定パラメータ上限を理由に除外しない |
| 技能の多様性・情報量の最大化 | [DIAYN](https://arxiv.org/abs/1802.06070)、[Variational Intrinsic Control](https://arxiv.org/abs/1611.07507) | 技能を区別する情報目的を与える。内的評価が進化する条件との比較候補 |
| 驚きの最小化 | [SMiRL](https://arxiv.org/abs/1912.05510) | 課題別報酬が不要でも、予測しやすい状況を求める目的は指定される。驚きを求める案と避ける案の比較として保留 |
| Novelty Searchによる個体や系統の選抜 | Lehman & Stanley。追加レビュー§1.1 | 新規性を管理側の選抜基準にする方式は、世界内の出生・死亡だけで系統が変わる主条件とは異なる。観測者の新規性指標として使う場合は別 |

## 具体化した方式と残る候補

| 候補 | v0への反映状況 | 次に判断すること |
| --- | --- | --- |
| [Stream-X / Stream-AC](https://arxiv.org/abs/2410.14606) | 変更して採用。[学習更新仕様](../protocols/learning-protocol-v0.md)で個体別正規化、適格度トレース、StreamingOptimizer由来の更新式、状態リセットを定義済み | GRUの予測学習、RLはヘッドのみ、密な初期化等が原方式との差分。完全なStream-X再現や性能保証とは扱わず、Phase 0で検査する |
| Stream-Xの疎初期化 | 原方式の一部だが、v0基準では採用しない | v0は全方式でfan-in基準の密な初期化をそろえる。疎初期化は別の比較候補として残す |
| [Continual Backpropagation / Dohareら](https://www.nature.com/articles/s41586-024-07711-7) | 比較候補。未使用ユニットの再初期化はv0に明記されていない | 継続学習の可塑性低下を測り、対策なし・ありを同じ予算で比較する |
| 通信を促す補助目的や帰納バイアス | [Eccles et al.](https://arxiv.org/abs/1912.05676)、[Ndousse et al.](https://arxiv.org/abs/2010.00581)。予測学習の考え方はL2/L3に一部反映 | signaling/listeningを促す項や、他者についての特定の予測目的は未指定。「予測なしでは通信が不可能」と一般化しない |
| Auto-teachingによる教師信号生成 | Nolfi & Parisi。追加レビュー§3.3 | 内的スカラー報酬とは別の学習信号生成法。外側の選抜、更新の安定性、L3との差を精読してから判断する |
| 通信のlanguage game・文化伝達 | [Sendra-Arranz & Gutiérrez](https://doi.org/10.1016/j.asoc.2026.115879)、Kirbyら。追加レビュー§3.5 | 記事本文は未読。通信手順や成否フィードバックの有無を確認する。自然な観察による学習と、管理側が用意する伝達課題を区別する |
| Minimal criterionによる繁殖制限 | [Chromaria / Soros & Stanley](https://wiki.santafe.edu/images/9/9c/Soros_alife14.pdf) | 追加レビューの候補。v0は成熟・エネルギー・場所等の身体条件を使う。別の設計者指定基準を加えるかは未選定 |

遺伝する評価器の係数が生涯中固定であるv0のL3と、評価器自身が経験から変わる後続案を混同しない。また、他個体を見たり聞いたりして学ぶことは、活動中に重み・勾配・経験バッファを直接共有することとは異なる。文化伝達を禁止した決定はない。

## v0レビューへの対応状況

以下は先行研究の採否とは別の実装前の修正点である。2026年10月11日に実験計画と学習更新仕様へ反映した。状態は「仕様へ反映済み」であり、コードの実装・GPU実測・学習成功を確認済みという意味ではない。

| 項目 | 修正内容 | 確認する条件 |
| --- | --- | --- |
| 出生時の資源量 | 創始個体50、子30に分離。両繁殖方式とも親の合計支払40、散逸10。不成立なら引落しなし | 出生・競合・容量拒否で資源が増えず、親子の収支が一致する（計画§2.3） |
| 個体を積んだテンソルのAdam | 個体別のm・v・実更新回数、出生時の全状態初期化、死亡枠の更新停止を指定。L3のRLは別の更新制御を使う | 独立Adamと関数型更新を同じ勾配列で照合し、枠再利用・無更新を含めて一致を検査する（学習更新仕様） |
| 突然変異の尺度 | 重みのfan-in相対尺度、正の率のlog変異、有界係数のclipを定義。mu=0.01/0.05/0.10 | 正の学習率と有限値を保ち、層別RMSと行動分布の変化を記録する（計画§3.1） |
| 一要因スクリーニング後の絞り込み | 通信×繁殖方式、学習方式×寿命、変異×モデル幅をPhase 2で保持。Phase 3の20%を全要因範囲の探索へ配分 | 主効果の小ささだけで組合せを除かず、重複セル・未実行セル・対応ありシードを記録する（計画§6） |
| L3の再現可能な更新手順 | 適用版の更新式、BPTT長1、初期値、正規化、独立optimizer、終端処理を定義 | 予測・RL・遺伝の更新を区別し、符号、更新上限、状態漏れをPhase 0で検査する（学習更新仕様） |
| v1への移行条件 | 較正と短い4方式パイロット後に小規模統合を計画。大規模掃引前に総GPU時間の10%を予約 | 実測に基づいてv0とv1の予算を固定し、v0の感度だけで睡眠・自己修正を却下しない（計画§8.1） |

## 未採用と混同しない現在の比較条件

- L0の重み固定・再帰状態、L1の局所可塑性、L2の感覚予測、L3の遺伝評価器による行動学習は、いずれもv0の比較対象である。まだ一方式を選んで他を却下した段階ではない。
- 体内感覚ありとなし、通信記号数、自己複製のみ・二親のみ・両方、個体数、モデル幅などはv0の要因である。通信を使うことと、通信を促す補助報酬を入れることも別である。
- [Loweらの通信測定の注意点](https://arxiv.org/abs/1903.05168)は、受信介入の参考として調査した。v0の測定表は発信頻度・エントロピーが中心で、受信だけを変える介入はまだ明記されていない。発信の相関だけを意味ある通信の成立と判定しない。
- 独立ネットワークのパラメータ、記憶、経験、勾配を保持する方針は採用済みの条件であり、個体軸のバッチ化と両立させる。並列化そのものを見送ったわけではない。
- 個体数とパラメータ数は固定条件を外している。過去の8個体や特定パラメータ数を、これらの候補の採否理由として復活させない。

## 再検討時に残す記録

候補を追加・除外する際は、対象機構、変更する入力や学習目的、元の論文との差分、計算費用、比較条件を記録する。理由が「現在の方針との不整合」なのか、「切り分けのための延期」なのか、「資料不足・未測定」なのかを区別する。

科学的な効果、今回の条件への適合、実装上の費用は別々に判断する。未実装や未選定という事実だけで「効かない」と結論しない。
